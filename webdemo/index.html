FEATURES

先把标准键盘和墨水屏做对

不依赖云输入，不收集输入内容；布局和候选都在本机完成。

标准键盘能力

Ctrl / Alt / Shift、Tab / Esc、方向键和符号层都能组合；修饰键支持粘滞与锁定，适合终端、IDE 和远程桌面。

墨水屏友好

整数像素网格、Unifont 点阵字和四色高对比，不使用渐变、阴影或半透明；在静态刷新设备上边界更清晰。

隐私安全

不申请网络权限，不上传输入内容；词典、自学习词库和设置只保存在本机，卸载即清除。

全拼 + 5 种双拼

全拼、小鹤、自然码、智能ABC、中文之星、国标。默认全拼，长按空格输入 \zh=方案 切换。

整数像素自适应

按窗口宽高与底部安全区计算几何，竖屏与横屏共用一套算法；键宽、字号、缝隙按整数推进。

自学习与上文

常用词和上一句上下文参与候选，跨输入框保留 10 字上文；切换应用不会丢上下文。

AUDIENCE

适合谁，不适合谁

KBD 不是全能输入法；它优先服务一类明确的需求。

适合

  • 既要日常中文输入，也要标准键盘快捷键的极客
  • 终端、IDE、远程桌面、SSH 等需要 Tab / Esc / Ctrl 的场景
  • 墨水屏设备：阅读为主，但偶尔需要中文输入
  • 在意离线、无网络权限和本地词库的用户

不适合

  • 只习惯九宫格输入的用户（KBD 只提供 26 键布局）
  • 依赖语音输入的用户（KBD 不提供语音）
  • 追求花哨皮肤、动画或云输入的用户

墨水屏用户通常以阅读为主；KBD 不是阅读器输入方案，但在需要输入时，它的布局比常见输入法更可控。

SCHEMES

六种输入方案

INSTALL

三步开始使用

  1. 01

    启用 KBD

    系统设置 → 语言与输入法 → 启用 KBD。

  2. 02

    设为当前输入法

    在输入框中调出键盘，切换到 KBD。

  3. 03

    开始输入

    中/英切换，长按中/英打开符号层，长按空格进入转义命令。

前往下载 Android 8.0+ · arm64-v8a · 与旧版同签名可覆盖升级
