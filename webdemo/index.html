FEATURES

为中文输入重做的键盘

不依赖云输入，不收集输入内容；布局和候选都在本机完成。

整数像素自适应

按窗口宽高与底部安全区计算模式和几何，键宽、字号、缝隙按整数推进；竖屏与横屏共用一套算法。

全拼 + 5 种双拼

全拼、小鹤、自然码、智能ABC、中文之星、国标。长按空格后输入 \zh=方案 即可切换。

离线与隐私

词典与语言模型随应用内置，不申请网络权限，不上传输入内容；自学习词库只保存在本机。

自学习与上文

常用词和上一句上下文参与候选，跨输入框保留 10 字上文；切换应用不会丢上下文。

四色主题

深/浅两套四色皮肤，\sk=dark|light|auto 切换；无边框按键只比背景亮一档。

标准键盘能力

Ctrl / Alt / Shift 组合键、Tab / Esc、方向键、符号层翻页、长按锁定与连发。

SCHEMES

六种输入方案

默认全拼；其余为 26 键双拼，不使用非字母键。点选可切换上方试用键盘。

INSTALL

三步开始使用

  1. 01

    启用 KBD

    系统设置 → 语言与输入法 → 启用 KBD。

  2. 02

    设为当前输入法

    在输入框中调出键盘，切换到 KBD。

  3. 03

    开始输入

    中/英切换，长按中/英打开符号层，长按空格进入转义命令。

前往下载 Android 8.0+ · arm64-v8a · 与 1.2 同签名可覆盖升级
