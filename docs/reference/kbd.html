操作说明：
1. Shift/Ctrl/Alt：短按切换状态，反色提示；长按锁定，再次按自身取消
2. 中英：短按切换中/英，长按进入符号模式（显示「符」）；第三行无下滑，符号全部在上滑层
3. 第三行：z上滑=Esc，x上滑=<，c上滑=>，v上滑=?，b/n/m上滑为中文标点
4. 方向键：单击单步、按住连续移动；↑上滑=Tab
5. 空格：单击空格，长按进入转义模式；确认：单击换行，长按收起键盘
