## 0. 摘要与关键假设

本项目实现一款 Android 系统输入法，沿用原型中的 10 列 × 4 行网格键盘，支持中英文、符号页、修饰键、方向键与转义模式，中文输入后端倾向使用 libime。

关键假设：

| 项目 | 假设 |
| --- | --- |
| 设备 | Android，arm64-v8a（v8a），无物理键盘 |
| 屏幕 | 720 × 1604 竖屏 + 1604 × 720 横屏，两种方向都支持；竖屏为主形态 |
| 键盘基准 | 竖屏以 720 宽为设计基准；横屏使用独立尺寸档，不按屏宽等比放大 |
| 字体 | 全部使用内置 Unifont（随 APK 打包；授权与字形覆盖需核实） |
| 形态 | 系统输入法（InputMethodService），不是独立编辑器 |
| 后端 | libime（倾向，开发前二次讨论定案） |
| 路线 | 路线一：先用 Web demo 冻结交互与布局，再进入原生开发 |

一句话方案：**原生 Kotlin 自定义 View 负责渲染与触摸状态机；布局与状态机数据化；libime 通过 JNI 提供拼音候选；Web demo 复用同一份布局规则与交互规格，用来冻结体验。**

### 0.1 已确认决策

| 决策 | 结论 | 影响 |
| --- | --- | --- |
| 开发路线 | 路线一：Web demo 先行 | 先产出可评审的浏览器 demo，再写原生 |
| 屏幕方向 | 竖屏 + 横屏都支持，竖屏为主 | 需要两套尺寸档，Web demo 两个方向都要验收 |
| 修饰键 | 纯粘滞（sticky），不做按住组合 | 组合键通过“点修饰键 → 点目标键”完成 |
| 转义模式 | 转义解析窗口：`\n`、`\t`、`\uXXXX` / `\u{...}` + 可扩展命令 | 空格执行转义，长空格退出；不是字面上屏 |
| 主要场景 | 日常聊天/笔记 + 终端/代码，两者兼顾 | 方向键、Esc/Tab、Ctrl/Alt 与中文候选都要验收 |
| 字体 | 全部内置 Unifont；键盘内所有文字统一 **32px**，无例外 | 键面、候选、拼音、页码全部 32px；像素对齐、不模糊 |
| 键高 | 每个按键 3 个字符高 = **96px** | 上下滑与主键各占一行；候选行与按键文字行对齐 |
| 竖屏网格 | 14 行连续 32px 字：拼音 1 + 候选 1 + 主键 9 + 功能 3 | 纵向不留额外按键间距；横向列距 4 |
| 候选区 | 无按键；竖屏常驻 1 行，横屏 6 个文字行 | 候选与键位网格对齐，不破坏列宽 |
| 展开候选 | 有拼音时确认键变成“展开”，展开后变成“返回” | 去掉 `>` 展开箭头与候选分页控件 |
| 展开网格 | 竖屏仍 14 行：主键 9 行变成 9 行候选；横屏 6 行候选 | 竖屏常驻候选行保留；拼音行不占整行 |
| 拼音行 | 不是整行，只在拼音文字后加背景色；浮动 | 竖屏在候选行上方；横屏只在候选区上方 |
| 候选宽度 | 最小等于确认键宽度，动态对齐网格 | 竖屏 140；横屏 124 |
| 中文模式 Shift | 无拼音缓冲时直接上屏大写英文；有拼音时不隐式上屏 | 有拼音时忽略并保持拼音 |
| 无拼音时确认 | 执行编辑器动作 / 换行 | 有拼音时确认改为展开 / 返回，不上屏原文 |
| 无隐式上屏 | 空格上屏首选词，点击候选上屏；其他操作不提交 | 方向、切语言、符号、转义都不隐式提交 |
| 横屏布局 | 三行分栏 + 中间候选面板 | 左右各 5 个字母列；g 在右簇；面板正好占中间区 |
| 横屏符号 | 中间 20 列 × 3 行，60/页 | 扁平列表自动填充；无空格；与转义互斥 |
| 符号去重 | 排除中英文模式已能打出的符号 | 按所有键的上滑/下滑标签精确匹配，并去重；方向键主标签是导航，不参与过滤 |
| 符号页码 | 中/英键三行：`n` / `符` / `N` | 竖横屏一致；全部 32px；不再显示 `n/N` 一行 |
| 安全边距 | 竖屏只上移，横屏只缩左右；两边相等；R 固定 | 不做运行时滑杆；只适配物理屏幕四角；按键无圆角 |
| 中文符号 | 对齐 PC 搜狗中文标点方案 | 例如 k 上滑 `{`，不是 `《`；不是全部全角 |
| 拼音缓冲 | 单行 | 预编辑只占一行；超出单行宽度时截断/滚动，不自动提交 |
| 无标签滑动 | 空滑动，不输出 | 滑到无标签方向释放时不产生字符 |
| 主题默认 | 跟随系统 | 用户可在设置覆盖 |
| 收起键盘 | 仅确认键长按 | 有拼音时不收起、不响应 |
| 键盘提示 | 键盘内只保留功能标签、候选、拼音、符号页码 | 不显示模式、帮助、转义预览、占位等额外提示 |

### 0.2 原型中已明确的规则

- 10 列键位；3 行字母/功能行 + 1 行底部功能键（竖屏）。
- 每个字母键有“上滑 / 主键 / 下滑”三层，上下滑用纵向位移触发；三层各占一个 32px 文字行。
- Shift/Ctrl/Alt：短按切换状态并反色，长按锁定，再次按自身取消。
- 中英键：短按切换中/英，长按进入符号模式（键面显示“符”与页码）。
- 符号层：竖屏 3 行 × 10 列（30/页），横屏 3 行 × 20 列（60/页）；页数按过滤后的扁平列表动态计算。
- 第三行（z–m）没有下滑层。
- 方向键单击单步、按住连续移动；所有箭头**没有**上下滑绑定；Tab 在 a 上滑。
- 空格单击输入空格，长按进入转义模式；确认键单击在无拼音时换行，长按收起键盘。
- 转义模式缓冲、上屏与退出（原型的上屏走 Mock 编辑器）；不显示预览/帮助。
- 符号层没有 `>` 翻页箭头；纵向滑动翻页。
- 候选层没有 `>` 展开箭头；确认键负责展开 / 返回。

### 0.3 本稿必须补齐的部分

1. 候选区 / 拼音浮动行的完整尺寸与对齐规则。
2. 展开候选的进入、退出、容量与渲染。
3. 字母键在非转义模式下的上屏逻辑；修饰键的实际作用。
4. 方向键长按连续移动；a 上滑 Tab；箭头无滑层。
5. 删除键的退格、删拼音、删转义缓冲规则。
6. 转义模式的真正语义（`\n`/`\t`/`\u` 与扩展命令）。
7. 滑动与长按的优先级、取消规则、多指处理、边界情况。
8. 符号页去重、页码与翻页提示。
9. 中文输入时的标点、空格、删除、回车、切换语言规则。
10. 主题切换进入设置页，不留在键盘界面。

## 1. 目标与非目标

### 1.1 目标

- 在 720 × 1604 竖屏与 1604 × 720 横屏上提供可日常使用的中英文输入；竖屏为主形态。
- 保留原型的“每键三层 + 功能键长按”的低层级交互，尽量减少切页。
- 中文拼音输入具备：预编辑、候选、展开、选词、上屏、退格、标点。
- 兼顾终端 / 代码场景：Esc、Tab、方向键、Ctrl/Alt 组合、转义模式。
- 状态可见：修饰键、中英、符号页、转义缓冲都有明确反馈。
- 低延迟、低内存、适合慢刷新屏幕（如墨水屏）。
- 全键盘像素对齐，字体不模糊；候选与按键网格对齐。

### 1.2 非目标（永久不做）

以下内容全部不做，后续也不做：

- 手写、语音、表情、云候选、皮肤市场。
- 除中英以外的语言。
- 滑行输入（swipe typing）、九宫格、26 键传统布局。
- 用户自定义布局编辑器。
- 平板、折叠屏、自由窗口的额外适配（横屏已列入范围）。
- 联网、账号、同步。

## 2. 屏幕与尺寸模型

两种方向使用两套尺寸档：竖屏 10 列 × 4 行；横屏 3 行分栏。所有键宽、键高、间距、候选格均为整数，不出现小数。

### 2.1 竖屏档（720 × 1604）

| 名称 | 数值 | 说明 |
| --- | --- | --- |
| 屏宽 W | 720 | 竖屏设计基准 |
| 列数 | 10 | 每行固定 10 列 |
| 横向列距 g | 4 | 纵向不留额外间距 |
| 栅格余量 | 2 | 每侧 2，10×68 + 9×4 + 2×2 = 720；不是安全边距 |
| 单列宽 u | **68** | 字母 / 方向键 |
| 双列宽 | 2u + g = **140** | 空格 / 删除 / 确认；也是候选格最小宽度 |
| 键高 h | **96** | 3 × 32px 文字行 |
| 主键区高 | 3×96 = **288** | 三行字母/符号，行间无纵向间距 |
| 候选行高 | **32** | 字母层常驻；紧贴主键区 |
| 功能行高 | **96** | 第 4 行；标签在中间一行居中 |
| 键盘高（字母/展开） | 32 + 288 + 96 = **416 + R** | R=16 → 432 |
| 键盘高（符号） | 288 + 96 = **384 + R** | 无候选行；R=16 → 400 |
| 14 行字 | 拼音 1 + 候选 1 + 主键 9 + 功能 3 | 全部 32px；纵向连续 |
| 应用区（字母） | 1604 − 416 − R | R=16 → 1172 |
| 字号 | **32** | 键盘内所有文字，无例外 |
| 安全边距 | 仅底部 R | 只上移，不缩左右；按键无圆角 |

竖屏字母层与符号层的键位保持同一 y 位置：符号层去掉顶部 32px 候选行，功能行与主键行位置不变，应用区多出 32px。展开时保持同样的 14 行：拼音 1 行、常驻候选 1 行、9 行候选、功能 3 行。

### 2.2 横屏档（1604 × 720，三行分栏）

横屏为“左右分栏 + 中间候选面板”的三行布局。安全边距只缩左右、不上移：

| 项目 | 数值（R=16） | 说明 |
| --- | --- | --- |
| 屏宽 W | 1604 | |
| 左右安全边距 R | 实测后固定；原型 16 | 键盘宽 `W_eff = 1604 − 2R`；不做运行时调整 |
| 行数 | 3 | 字母三行 |
| 键高 h | **96** | 3 × 32px 文字行 |
| 行间距 g | 4 | |
| 键盘高 | 3×96 + 2×4 = **296** | 无底部安全边距 |
| 外列宽 F | **140 − R**（R=16 → 124） | 安全边距由外列吸收；左列 Alt/Ctrl/Shift，右列 删除/中英/确认 |
| 字母/方向键宽 K | **76** | 每行左右各 5 个 |
| 空格/候选面板宽 | **固定 516** | 不随 R 改变；候选面板 516×196，空格 516×96 |
| 中间区 x | F + g + 5K + 5g = **528**（R=16） | 左簇结束后一个 4px 间距 |
| 候选格 | **124 × 32**，4 列 × 6 行 | 4×124 + 5×4 = 516；最小宽 = 确认键 124 |
| 空格 | **516 × 96** | 第三行中间，宽度固定 |
| 符号区 | 20 列 × 3 行 | 中间宽 **固定 1316**；键 62、间距 4，20×62+19×4=1316 |
| 拼音行 | **32px 高，仅文字背景** | 只在候选面板正上方，x=528、宽 516；不占整行、不在主键盘上方 |
| 展开候选 | 中间区 **1316 × 296** | 与符号模式中间区间同 x、同宽、同高；6 行 × 40；10×6 格 128×40；外列保留，确认键变返回 |
| 输入视图高 | **296** | 占 720 的 41%，应用区约 424 |
| 字号 | **32** | 键盘内所有文字，无例外 |

列位置（R=16，键盘坐标）：

```text
0        124 128                524 528                1044 1048               1444 1448      1572
[ F 124 ]g[ 5×K=396 ]g[    C=516         ]g[ 5×K=396 ]g[ F 124 ]
```

- F=124，K=76，g=4；左簇 5 键、右簇 5 键，三行完全对齐，不再有行错位。
- R1：左 q–t，右 y–p；R2：左 ↑ a s d f，右 **g h j k l**；R3：左 ↓ z x c v，右 b n m ← →。
- 候选面板正好占中间区 C，左右与字母簇各隔 4px；空格在第三行同一中间区。

### 2.3 像素对齐与安全边距

- 所有尺寸为整数像素；非整数余量必须成对分配，保证左右边距相等。
- 横屏左右安全边距各 R；竖屏只有底部 R，左右各 2 是栅格余量，不属于安全边距。
- 竖屏纵向为连续 32px 行网格：候选行与主键行、功能行之间不留额外纵向间距；横向列距仍为 4。
- **安全边距 R 是固定值**（原型固定 16，实测后写死），不在运行时调整。横屏由外列吸收安全边距：F = 140 − R（R=16 →124）；空格/候选面板固定 516，符号中间区固定 1316，不随 R 改变。
- 横屏候选格宽 = `floor((C − 5g)/4)`；4 个候选 + 5 个 4px 间隙正好填满 516。R=16 时 124，与确认键同宽。
- 符号中间区固定 1316：20×62 + 19×4 = 1316，所有间距（含与外壳的间距）都是 4。
- 展开候选区与符号模式同区间：x=symX、宽=1316；10×128 + 9×4 = 1316，R=16 时 10 列 ×128。
- 展开时横屏保留左右外列；确认键在原位置变成“返回”，不再使用整列返回键。
- 按键无圆角；只有物理屏幕四角需要安全适配。

### 2.4 字号

- 键盘内所有文字固定 **32px**：键面三层、候选词、拼音、符号页码、展开行。
- **没有例外**：不再使用 16px 页码、16px 帮助或 16px 空格缓冲；也不用 18/22/24/28。
- 所有文字使用 Unifont，关闭字体平滑；行高 1（32px），三层文字行各 32px。
- 单键（无上下滑、功能键、符号键）在键内垂直居中；第四行功能键标签居中。

## 3. 键盘布局

### 3.1 总览（字母层，竖屏）

```text
拼音行   ni'hao                                      ← 32px，仅文字背景
候选行  [候选 1] [候选 2] [候选 3] [候选 4] [候选 5]  ← 32px，常驻，紧贴主键
R1      [q] [w] [e] [r] [t] [y] [u] [i] [o] [p]
R2      [↑] [a] [s] [d] [f] [g] [h] [j] [k] [l]
R3      [↓] [z] [x] [c] [v] [b] [n] [m] [←] [→]
R4      [Shift] [Ctrl] [Alt] [中/英] [空格 ×2] [删除 ×2] [确认 ×2]
```

竖屏共 14 行、行距 32px：拼音 1 + 候选 1 + R1–R3 的 9 + R4 的 3。横屏的三行分栏布局见 3.8。

### 3.2 R1：数字 / 符号行

主键为字母；上滑为数字；下滑在英文模式为半角符号，中文模式按搜狗中文标点方案转换，**不是全部全角**。

| 列 | 主键 | 上滑 | 下滑（英） | 下滑（中） |
| --- | --- | --- | --- | --- |
| 1 | q | 1 | ! | ！ |
| 2 | w | 2 | @ | @ |
| 3 | e | 3 | # | # |
| 4 | r | 4 | $ | ￥ |
| 5 | t | 5 | % | % |
| 6 | y | 6 | ^ | …… |
| 7 | u | 7 | & | & |
| 8 | i | 8 | * | × |
| 9 | o | 9 | ( | （ |
| 10 | p | 0 | ) | ） |

数字上滑始终输出半角，不受中英模式影响。

### 3.3 R2：导航上 / 字母 a–l

| 列 | 主键 | 上滑（英） | 上滑（中） | 下滑（英） | 下滑（中） |
| --- | --- | --- | --- | --- | --- |
| 1 | ↑ | — | — | — | — |
| 2 | a | Tab | Tab | — | — |
| 3 | s | ~ | ～ | ` | ` |
| 4 | d | : | ： | ; | ； |
| 5 | f | " | “ | ' | ‘ |
| 6 | g | \| | \| | \ | 、 |
| 7 | h | + | + | = | = |
| 8 | j | _ | —— | - | - |
| 9 | k | { | { | [ | 【 |
| 10 | l | } | } | ] | 】 |

注：Tab 只在 `a` 上滑；所有箭头没有上下滑。`k/l` 上滑按搜狗中文标点保持 `{}`，不是 `《》`；`[`/`]` 中文下滑仍为 `【】`。横屏拆分时 **g 属于右簇**（左簇 ↑ a s d f，右簇 g h j k l）。

### 3.4 R3：导航下 / 字母 z–m / 左右方向

第三行没有下滑层。

| 列 | 主键 | 上滑（英） | 上滑（中） |
| --- | --- | --- | --- |
| 1 | ↓ | — | — |
| 2 | z | Esc | Esc |
| 3 | x | < | 《 |
| 4 | c | > | 》 |
| 5 | v | ? | ？ |
| 6 | b | , | ， |
| 7 | n | . | 。 |
| 8 | m | / | / |
| 9 | ← | — | — |
| 10 | → | — | — |

`x/c` 上滑中文为《/》；`m` 上滑保持 `/`；所有箭头没有滑层。

### 3.5 R4：功能行（竖屏）

| 列跨度 | 键 | 单击 | 长按 |
| --- | --- | --- | --- |
| 1 | Shift | 切换临时大写态；再按取消 | 锁定 / 解锁大写 |
| 1 | Ctrl | 切换临时 Ctrl 态；再按取消 | 锁定 / 解锁 |
| 1 | Alt | 切换临时 Alt 态；再按取消 | 锁定 / 解锁 |
| 1 | 中/英 | 切中/英；符号模式中退出 | 进入符号模式（键面显示“符”与页码） |
| 2 | 空格 | 输入空格；拼音输入中选首选候选；转义中执行 | 进入转义模式；转义模式中退出 |
| 2 | 删除 | 退格；拼音输入中删拼音；转义中删缓冲末字符 | 连续删除 |

横屏功能键不在底行，而是分布在左右外列，见 3.8。

### 3.6 符号层

- 符号数据是一维扁平列表，不固定每行内容；按当前方向槽位自动换行填充。
- 竖屏：3 行 × 10 列 = 30 个/页，替换 R1–R3；R4 保持不变；没有候选行（键盘高 384 + R）。
- 横屏：左右外列保留，中间 3 行 × 20 列 = 60 个/页；没有空格键。
- 进入方式：长按中/英键；退出方式：符号模式中短按或长按中/英键。
- 翻页：在符号区域纵向滑动 ≥ 30 px，循环翻页；不显示 `>` 或翻页按钮。
- 页码显示：**中/英键三行**，从上到下 `n` / `符` / `N`，全部 32px；竖横屏一致。候选区/候选条不显示符号页码。
- 符号键单击直接上屏；符号层没有上下滑层。
- 符号键在竖屏转义模式中可追加到转义缓冲；横屏符号模式与转义互斥。
- 符号清单排除中英文模式已能打出的符号：按所有键的上滑/下滑标签（中/英两种形态）精确匹配并去重。例如 `，。！？、；：（）《》【】￥……×～——` 等不再出现在符号页；`”’` 等不能直接由键面打出的符号仍保留。方向键主标签是光标导航，不是字符上屏，因此 `↑↓←→` 仍保留在符号页。
- 当前原型过滤后 426 个符号：竖屏 15 页，横屏 8 页；最终按 PC 搜狗“符号大全”补齐后页数动态变化。见附录 B。

### 3.7 候选区（竖屏 / 横屏）

候选区不含按键，但按键盘网格对齐：

| 方向档 | 位置 | 尺寸 | 结构 | 可显示候选 |
| --- | --- | --- | --- | --- |
| 竖屏普通 | 键盘顶部独立行 | 720 × 32 | 5 格 × 140，间距 4，两侧 2 | 5 |
| 竖屏展开 | 主键区 9 行 | 720 × 288（y=32） | 5 列 × 9 行，格 140×32 | 45（+顶部常驻 5 = 50） |
| 横屏普通 | 键盘中间面板 | C × 196（R=16 → 516×196） | 4 列 × 6 行，格 124×32 | 24 |
| 横屏展开 | 6 行候选背景 | 1316 × 240（R=16，y=48） | 10 列 × 6 行，格 128×40 | 60 |

- 竖屏候选格宽 = 确认键宽（双列 140）；5×140 + 4×4 + 2×2 = 720。
- 横屏普通候选格宽 = 124（= 确认键宽）；4×124 + 5×4 = 516。展开候选格 128×40，10×128 + 9×4 = 1316。
- 横屏 6 行的 y 为 0、32、64、100、132、164：前三行与 R1 键的上/主/下文字行逐行对齐，第四至六行与 R2 对齐；中间 4px 正好是两行按键之间的间距。
- 竖屏候选行在字母层常驻（无候选时留空）；符号层没有候选行。候选行与主键行紧贴，不留纵向间距。
- 拼音不是整行：只在拼音文字后加背景色，浮在候选区上方（见 3.11）；展开时也不占整行。
- 无 `>`、无页码、无候选翻页控件；超过当前区容量的候选通过“展开”查看。
- 点击候选直接上屏；点击空白不产生输入。
- 候选与拼音统一 Unifont 32px；超长候选省略号截断，点击仍上屏完整文本。

### 3.8 横屏布局（已定分栏）

```text
R1  [Alt] [q][w][e][r][t]    ┌ 候选 4×6（无按键） ┐   [y][u][i][o][p] [删除]
R2  [Ctrl][↑][a][s][d][f]    │ 6 个 32px 文字行   │   [g][h][j][k][l] [中/英]
R3  [Shift][↓][z][x][c][v] [      空 格  C      ]   [b][n][m][←][→] [确认]
```

- 左列自上而下：Alt、Ctrl、Shift；右列自上而下：删除、中/英、确认。
- 方向键与竖屏同构：↑ 在 R2 左、↓ 在 R3 左、←/→ 在 R3 右。
- 左右字母簇各 5 键，三行完全对齐；g 在右簇。
- 空格在 v 与 b 之间，宽 **固定 516**；外列 F=140−R 吸收安全边距，空格宽度不随 R 改变。
- 候选面板与空格同宽、同在中间区；面板跨 R1–R2，空格在 R3。
- 拼音只在候选面板正上方：x=面板 x、宽=面板宽；主键盘外列/字母簇上方没有拼音行。
- 横屏只缩左右、不上移：左右各 R，无底部安全边距。

### 3.9 横屏符号层（20 列 / 3 行）

- 左右外列保留；中间全部作为符号：3 行，20 列。
- 中间可用宽 1316；20 列：20×62 + 19×4 = 1316，键 62、间距 4，左右与外壳间距也是 4。
- 符号是扁平列表，按 60/页自动填充；页数按过滤后的列表长度计算。
- 符号模式下没有空格键；需要空格时点中/英键退出符号模式。
- 横屏符号模式与转义模式互斥：进入符号模式时退出转义模式。
- 页码显示在中/英键三行：`n` / `符` / `N`，全部 32px。

### 3.10 展开候选（已定）

- 触发：有拼音缓冲时，确认键显示“展开”；点击进入展开态。无拼音时确认键仍是“确认”。
- 返回：展开态确认键显示“返回”；点击回到普通候选态，拼音与候选保留。
- 竖屏：仍然 14 行。拼音 1 行 + 常驻候选行 1 行 + 主键区 9 行 + 功能行 3 行。展开时主键区那 9 个文字行直接变成 **9 行候选**（y=32..320，5 列 × 140，格高 32），功能行保留在 y=320。
- 竖屏常驻候选行保留并显示候选 1–5；9 行展开区从候选 6 开始继续填充，容量 45，合计 50。没有额外行距或缩放，行距仍 32。
- 横屏：展开态保留左右外列（Alt/Ctrl/Shift 与 删除/中英/确认），中间区间与符号模式完全一致：x=128、宽=1316、高=296（R=16）。顶部 40px 为拼音行（只有文字背景），下方 y=48..288 为 6 行候选背景，10 列 × 128×40，容量 60。确认键在原位置（右列第三行，124×96）变成“返回”，不再是整列返回键。
- 横屏展开态的拼音行不是整行背景：只有拼音文字后有背景色；6 行候选的背景从 y=48 开始。
- 展开态候选点击直接上屏；上屏后退出展开与拼音态，恢复字母键。
- 展开态没有字母键、方向键、符号键；竖屏保留底部功能行（空格仍可选首选，删除仍可删拼音）。
- 无 `>` 箭头、无候选分页；展开区就是当前候选页的完整视图。
- libime 候选页大小建议：竖屏 50、横屏 60；普通态只显示前 5 / 24 个。若引擎页大小不同，由 EngineBridge 聚合或截断。**[待定]**

### 3.11 拼音行（已定）

- 拼音行**不是整行**：只有拼音文字后面有背景色（`--bar-bg`），文字区域之外透明；不绘制整行底色。
- 竖屏：拼音浮在常驻候选行正上方，占一个 32px 文字行；水平方向从 x=0 开始，只有文字宽度有背景。
- 横屏普通态：拼音只出现在候选面板正上方（x=panelX、宽=C），主键盘区上方没有拼音。
- 横屏展开态：拼音在 6 行候选背景上方，位于展开区顶部；仍只有文字背景，不占整行背景。
- 竖屏展开态：拼音仍在常驻候选行上方（不移动），14 行结构不变。
- 内容：拼音预编辑串；转义模式显示转义缓冲。转义不显示预览/帮助。
- 无拼音、无转义时不显示；不改变键盘高度。
- 原生实现需要与系统窗口裁剪协调：可用同层浮动绘制或 32px 覆盖层；最终在系统集成阶段确认。**[提案]**

## 4. 手势与状态机

### 4.1 阈值

| 手势 | 阈值 | 说明 |
| --- | --- | --- |
| 长按 | 500 ms | 与原型一致 |
| 滑动判定 | 纵向 ±25 px | 进入上滑 / 下滑态 |
| 滑动回中 | 纵向 ±12 px | 回中后取消滑动，回到待定态（滞回，允许纠正） |
| 方向键 / 删除连发 | 按住 500 ms 后每 60 ms 一次 | 首次动作在 500 ms 时触发 |
| 符号页翻页 | 纵向 ≥ 30 px | 纵向滑动优先翻页，不触发符号上屏 |
| 点按 | 释放时仍未进入滑动 / 长按 | 执行主键动作 |

阈值单位：Web demo 使用 CSS px；原生使用 dp，并按目标设备手感校准。键高统一 96；滑动阈值 25 px 若在横屏过于敏感，可降到 20–22 px。**[待定]**

### 4.2 一次触摸的完整判定

1. **按下**：命中键位，显示按下态（反色）；上下滑小标签隐藏，只保留主键标签；启动 500 ms 长按计时器。
2. **移动**：
   - 仍为待定态时，纵向位移达到 ±25 px 且该方向有标签 → 进入上滑 / 下滑态，取消长按计时器；主键与反方向标签隐藏，只把所选方向标签居中显示。
   - 已进入滑动态后，回中到 ±12 px 内 → 回到待定态，恢复只显示主键（上下滑标签仍隐藏），可重新选择方向。
   - 纵向位移未达阈值 → 保持待定态；横向抖动不触发任何动作。
   - 该方向没有标签 → 进入“空滑动”态：键面显示空白，释放时不上屏任何字符；回中后可取消空滑动并按主键处理。
3. **长按**：
   - 待定态持续 500 ms → 执行长按动作（修饰键锁定、空格进转义、中/英进符号、确认收起键盘）。
   - 方向键 / 删除 → 进入连发态，立即执行一次，之后每 60 ms 一次。
   - 字母键没有长按动作 → 继续待定，释放时照常上屏。
   - 长按一旦触发，滑动判定失效；连发过程中移动手指不改变动作。
4. **释放**：
   - 待定态 → 主键动作；释放后恢复三层标签显示。
   - 滑动态 → 对应方向标签上屏；释放后恢复三层标签显示。
   - 长按 / 连发态 → 结束动作，不再执行点按。
5. **取消**：
   - 触摸被系统打断（来电、通知、多任务）→ 取消本次手势，不产生输入。
   - 指针移出键盘区域较远（超过一行的距离）→ 取消本次手势。**[提案]**
   - 同一指针只属于一个键；手指从 A 滑到 B 不会触发 B。

### 4.3 多指

- 每个指针独立判定，最多同时跟踪 2 个指针。
- 两个字母键同时按下时，按释放顺序上屏；先释放者先上屏。
- 纯粘滞模型下不做按住组合；第二个指针按键独立上屏，修饰态按粘滞状态消耗。
- 第 3 个及以上指针忽略，避免误触。

### 4.4 修饰键状态机

| 状态 | 进入 | 表现 | 退出 |
| --- | --- | --- | --- |
| off | 初始 | 正常配色 | — |
| temp | 短按一次 | 反色 | 再次短按；或下一个非修饰键上屏后自动清除 |
| locked | 长按 500 ms | 反色（加小锁标记） | 再次短按 |

- 临时态作用于“下一个键”；锁定态持续作用于后续键，直到再次点按解锁。
- 字母、符号、方向、删除、确认、空格都会消耗临时修饰态；修饰键自身不消耗。
- Shift 额外控制字母显示大小写。
- Ctrl/Alt 不改变字母大小写，只改变自身反色状态与输出（见第 7 节）。
- 锁定态不会被自动清除，只能再次点按解锁。
- 进入转义模式时清除所有修饰态。**[提案]**

已确认采用纯粘滞（sticky）语义：不支持“按住修饰键 + 另一指按键”的 chord；组合键通过先点修饰键、再点目标键完成。长按仍用于锁定。若后续需要 chord，作为独立版本再评估，不进入 v1。

### 4.5 语言、图层、转义与展开

- 语言状态：`EN` / `ZH`，默认 `EN`（原型默认）。
- 图层状态：`letters` / `symbols`。
- 展开状态：`normal` / `expanded`，只在有拼音时存在。
- 符号页：页数按过滤后的扁平列表和当前槽位自动计算；竖屏 30/页，横屏 60/页，循环。
- 转义状态：`off` / `on`，缓冲最多 16 个字符（含开头的 `\`）。
- 互斥规则：
  - 符号模式与转义模式：竖屏可共存（符号键可追加进转义缓冲）；横屏互斥，进入符号模式时退出转义模式。
  - 有未上屏拼音时，进入符号模式 / 切语言 / 转义 / 方向移动都**不隐式提交**，忽略并保持拼音。
  - 有拼音时可进入展开；展开中仍禁止切语言、符号、转义与方向移动。
  - 拼音删空后自动退出展开，恢复普通字母层。
  - 收起键盘 / 切换输入框 / 失焦时，清空拼音、展开态、转义缓冲、临时修饰态；保留中英选择与主题。**[提案]**

### 5.3 符号键

- 单击上屏符号。
- 符号模式下纵向滑动翻页；滑动一旦越过 30 px，取消本次按键上屏。
- 横屏符号键占满左右外列之间的中间区；页码显示在中/英键上。
- 竖屏符号键在转义模式中追加到缓冲；横屏符号模式与转义互斥。
- 修饰键对符号键的作用：忽略 Ctrl/Alt，Shift 不影响符号。**[提案]**

### 5.4 候选键

- 单击上屏该候选，结束本轮拼音；展开态点击后退出展开并恢复字母层。
- 普通态容量：竖屏 5，横屏 24；展开态容量：竖屏 50（常驻 5 + 9 行 45），横屏 60。
- 点击区域：竖屏 140×32（普通与展开同高）；横屏 124×32（普通）/ 128×40（展开），均高于触控目标下限。
- 无候选时普通候选区留空；展开键仍可点，但展开区为空时无实际内容。
- 候选翻页/更多候选不由 `>` 触发；由确认键展开查看。**[待定：libime 页大小]**

### 5.5 转义模式（已定：转义解析窗口）

**进入 / 退出**

- 长按空格进入。若有未上屏拼音，忽略，不隐式提交。
- 单击空格：解析并执行缓冲，退出。
- 长按空格：退出，不执行。
- 收起键盘 / 失焦：退出并清空缓冲。
- 缓冲太长、非法转义：保持窗口并忽略，不上屏。

**缓冲**

- 初始为 `\`；最多 16 个字符（含 `\`），足够 `\u{10FFFF}`。
- 可追加：字母（小写）、数字、符号层符号、各键主/滑层中的可打印字符。
- 不追加：方向键、Tab/Esc 键本身、修饰键、中/英、确认、删除、空格。
- 删除键：删除缓冲末字符；退到只剩 `\` 后不再删除。长按删除连续删除。
- 符号模式可共存（竖屏）；横屏符号模式与转义互斥。
- 修饰键状态在进入时清空，转义模式中忽略修饰键。

**解析（可扩展）**

| 转义 | 结果 |
| --- | --- |
| `\n` | 换行（插入换行字符；与确认键“可能一样”但语义独立） |
| `\t` | 制表（插入 Tab 字符） |
| `\u4e2d` | U+4E2D → `中`（4 位十六进制） |
| `\u{1F600}` | 支持 1–6 位十六进制、全 Unicode |
| `\s` | 打开设置（命令扩展点；原型中无可见入口） |
| `\j` | 简繁切换（命令扩展点；原型中无动作） |
| `\\` | 反斜杠本身 |

**显示 / 输出**

- 拼音行只显示缓冲（如 `\u4e2d`），只在文字后有背景色；不显示预览、箭头或命令帮助。
- 竖屏符号层 + 转义时同样只在拼音行显示缓冲；候选区留空。
- 空格键主标签始终是“空格”，32px；不显示缓冲。
- 转义结果按字符/动作执行，不是把 `\n` 两个字符原样上屏。
- 需要真正的键盘事件时，仍使用 Esc/Tab/方向键与 Ctrl/Alt；转义模式用于字符与自定义操作。

## 6. 中文输入流程（libime）

### 6.1 状态

```text
Idle ──字母──> Composing(普通候选) ──确认(展开)──> Expanded(竖屏 9 行 / 横屏 6 行候选)
  │                  │                              │
  │                  ├─ 空格 / 点击候选 ─────────────┴──> Idle
  │                  ├─ 删除：退一个拼音字母；删空回 Idle
  │                  ├─ 标点 / 方向 / 切语言 / 符号 / 转义：忽略，保持拼音
  │                  └─ 失焦：清空
  └─ Expanded ──确认(返回)──> Composing(普通候选)
```

### 6.2 上屏规则

**只有两种显式提交：空格上屏首选候选、点击候选上屏候选词。确认键不提交原文，只负责展开 / 返回 /（无拼音时）换行。**

| 操作 | 有拼音缓冲 | 无拼音缓冲 |
| --- | --- | --- |
| 字母 | 追加拼音 | — |
| Shift + 字母 | 不隐式上屏，忽略并保持拼音 | 上屏大写 ASCII |
| 空格 | 上屏候选 1；若无候选，上屏原始拼音 | 上屏半角空格 |
| 标点（上/下滑） | 忽略并保持拼音 | 上屏标点 |
| 删除 | 删除拼音末字母；删空退出展开 | 退格 |
| 确认 | 普通态展开；展开态返回；不提交原文 | 执行编辑器动作 / 换行 |
| 方向键 | 忽略并保持拼音 | 移动光标 |
| 切语言 | 忽略并保持拼音 | 切换 |
| 候选点击 | 上屏该候选并结束本轮 | — |

其他规则：

- 拼音缓冲**单行**：不设固定字母上限，预编辑只占一行；超出单行宽度时截断/横向滚动，不换行、不自动提交。
- 无有效候选时（如 `zzzz`），候选列表退化为原始拼音；空格上屏原始拼音，不会卡住。
- 候选普通态只显示前 5（竖屏）/ 24（横屏）；展开态显示当前候选页全部（容量 50/60）。
- 预编辑与候选使用同一份拼音串；避免显示与上屏不一致。
- 中文标点按搜狗中文标点映射（例如 k 上滑 `{` 而不是 `《`），不是全部全角。
- 数字始终半角。
- 英文模式不产生拼音预编辑，直接 `commitText`。

### 6.3 与 libime 的边界

本稿只约定前端需要的接口语义，具体库版本、字典与线程模型在二次讨论中定案：

```text
EngineInput: 拼音串（无空格）
EngineOutput:
  preedit    分段后的拼音显示串（可选）
  candidates 候选文本列表（当前页）
  hasMore    是否还有下一页（v1 不使用翻页控件）

API:
  reset()
  update(pinyin: String) -> Result
  selectCandidate(index: Int) -> String
  nextPage() / prevPage()   // 预留；v1 界面不暴露
```

- 候选生成应可异步；用递增的 generation id 丢弃过期结果。
- 若查询在主线程可稳定在预算内，可同步调用；先测再定。
- v1 不再有候选翻页控件；建议把候选页大小配置为展开容量（50/60），普通态取前 5/24。若 libime 固定页大小，则由 EngineBridge 聚合或截断。**[待定]**
- 用户词频 / 自学习 v1 不做；若 libime 自带用户词典，可在 v1.1 打开。**[待定]**

## 7. 修饰键与按键事件

Android 输入法不能保证所有编辑器都接受任意按键事件，因此需要分层处理：

| 组合 | 输出方式 | 说明 |
| --- | --- | --- |
| Shift + 字母 | `commitText` 大写字母 | 最可靠 |
| Ctrl / Alt + 字母 | `sendKeyEvent(KeyEvent with META_CTRL/ALT)` | 终端、部分编辑器支持；普通 EditText 可能忽略 |
| Ctrl / Alt + 方向 / 删除 / Esc / Tab | `sendKeyEvent` 带 meta | 终端类应用的主要场景 |
| 无修饰的 Esc / Tab / 方向 | `sendKeyEvent`（DOWN + UP） | 不走 `commitText` |
| 回车 | `performEditorAction` 或 `commitText("\n")` | 按编辑器能力选择 |
| 退格 | `deleteSurroundingTextInCodePoints(1, 0)`；失败回退 `sendKeyEvent(KEYCODE_DEL)` | API 24+ |
| 文本 / 符号 / 空格 | `commitText` | 常规路径 |

注意：

- `Ctrl+C` 等组合在普通文本框中可能无效，这是 Android IME 的系统限制，不是键盘 bug。
- 转义模式是解析窗口（见 5.5），用于 `\n`/`\t`/`\u` 与自定义命令，不能替代真正的控制字符；若目标场景是终端，应优先使用 Esc/Tab/方向键与 Ctrl/Alt 组合。
- 修饰键 + 滑动符号的组合按 `KeyCharacterMap` 尽力转换；无法映射时忽略修饰并上屏字符。**[提案]**

## 8. 系统集成

- 组件：`InputMethodService` + 自定义 `InputView` + 候选/状态层（可合并在同一个自绘 View 中）。
- 输入视图尺寸：
  - 竖屏字母/展开：`416 + R`；竖屏符号：`384 + R`。
  - 横屏：三行键盘 `296`，左右各 R，无底部边距。
  - 竖屏拼音行浮在候选行上方，不占键盘高度；横屏普通态浮在候选面板上方（x=面板），展开态在展开区顶部、6 行候选背景上方。原生需确定同层浮动或 32px 覆盖层实现。**[提案]**
- `onEvaluateFullscreenMode()` 返回 `false`，避免横屏 / 小屏进入全屏提取模式。
- `onStartInput` / `onFinishInput` / `onStartInputView` 负责：读取 `EditorInfo`、重置状态、决定确认键行为。
- 密码 / 敏感输入框：不记录、不学习；候选仍可用。
- 输入法切换、返回键、通知打断：清空当前手势、拼音与展开态。
- 底部系统手势冲突：用 `setSystemGestureExclusionRects` 排除空格/删除/确认所在区域。
- 硬件键盘存在时仍显示软键盘；不做物理键盘映射。
- 主题：默认跟随系统深/浅色；提供“始终深色 / 始终浅色”设置。原型中的切换按钮不属于键盘，放到设置页。
- 触感反馈：可选，默认开启短震动（约 20 ms）；不提供按键音。
- 收起键盘：确认键长按；有拼音时不收起、不响应。
- 键盘高度：同一图层内固定，不因候选有无变化；切换字母层/符号层时高度差 32px（竖屏去掉候选行），切换展开态高度不变。

## 9. 前端实现架构

### 9.1 原生端（已选）

- 语言：Kotlin；单一 IME APK + 设置页。
- 渲染：一个自定义 `View` 自绘全部键位与候选区，不创建几十个子 View；只重绘脏区。
- 布局与状态分离：
  - `layout.json`：键位、宽度、各层标签、动作 id、长按动作、候选格规则。
  - `GestureResolver`：纯逻辑手势判定（可单元测试）。
  - `KeyboardState`：语言、图层、符号页、修饰态、转义缓冲、展开态。
  - `Renderer`：把状态画到 Canvas。
  - `ImeController`：把动作转成 `InputConnection` 调用。
  - `EngineBridge`：JNI ↔ libime。
- 键位命中测试与触摸跟踪放在容器层，避免原型中“每个键各自监听”带来的跨键、多指、touchend 归属问题。
- 字体：全部使用内置 Unifont（TTF/OTF 随 APK 打包）；键面、候选、预编辑统一；需核实授权与目标字符覆盖。
- 性能预算（待真机验证）：
  - 按下反馈 ≤ 1 帧；
  - 拼音预编辑更新 ≤ 100 ms；
  - 候选查询 p95 ≤ 50 ms；
  - 键盘冷启动可交互 ≤ 1 s，字典后台加载不阻塞输入；
  - 常驻内存目标 ≤ 150 MB（含字典）。

### 9.2 Web demo（路线一，已选）

- 技术：原生 JavaScript + CSS，无构建步骤；Pointer Events + `touch-action: none`；同一页面支持 720 × 1604 与 1604 × 720 两个视口。
- 方向档：竖屏按 2.1 节尺寸；横屏按 2.2 / 3.8 节三行分栏；旋转 / 改变窗口时实时切换档位，保留语言、主题与拼音状态。
- 像素：布局参数全部整数；演示页在桌面浏览器上会等比缩放，目标设备浏览器在 720p 下为 1:1。
- MockEngine：模拟 libime 的候选、展开、上屏；不实现真实翻页。
- 页面包含：可输入的文本框、候选区、浮动拼音行、键盘、设置（主题）。
- 目标：在目标设备浏览器上验证两种方向的手感、滑动阈值、候选/展开可读性、转义模式；冻结布局与交互规格。
- 不追求：真实 JNI、系统输入法行为、墨水屏刷新性能；这些必须原生阶段验证。
- 退出标准：第 13 节验收项在 Web 端可通过（除系统集成项），竖屏与横屏都通过，布局参数冻结，开放问题收敛。

### 9.3 数据驱动示例

```json
{
  "version": 2,
  "grid": {
    "portrait": { "cols": 10, "keyHeight": 96, "gap": 4, "side": 2 },
    "landscape": { "keyHeight": 96, "gap": 4, "outerWidth": 124, "keyWidth": 76 }
  },
  "candidate": {
    "portrait": { "normal": [5, 1], "expanded": [5, 9], "cellWidth": 140 },
    "landscape": { "normal": [4, 6], "expanded": [10, 6], "minCellWidth": 124 }
  },
  "rows": [
    {
      "keys": [
        {
          "id": "q",
          "width": 1,
          "main":  { "en": "q", "zh": "q" },
          "up":    { "en": "1", "zh": "1" },
          "down":  { "en": "!", "zh": "！" },
          "action": "letter"
        }
      ]
    }
  ]
}
```

动作类型建议：`letter`、`digit`、`symbol`、`nav`、`tab`、`esc`、`modifier`、`lang`、`space`、`backspace`、`enter`、`candidate`、`expand`、`collapse`。每个键只描述“是什么”，输出与状态转换由状态机决定。

`layout.json` 顶层按 `orientation` 提供两套 profile：`portrait`（10 列 × 4 行 + 32px 候选行 + 浮动拼音）与 `landscape`（3 行分栏 + 6 行候选面板 + 浮动拼音）；两套 profile 共用动作 id 与状态机。

## 10. 后端架构选型（二次讨论）

> 本节只列议题与初判，不在本稿定案。开发前必须单独讨论一次。

### 10.1 需求

- 中文拼音候选质量可用，支持连续输入、分词、展开查看。
- 冷启动与每次按键延迟可接受（目标设备）。
- 字典体积、内存占用可控；离线可用。
- arm64-v8a 可直接集成；构建链可维护。
- 许可允许分发（开源或闭源需分别评估）。
- 用户词频 / 自学习可扩展（v1.1）。

### 10.2 候选方案

| 方案 | 描述 | 优点 | 风险 |
| --- | --- | --- | --- |
| A. libime + JNI 同进程 | 把 libime 编译为 arm64-v8a 动态库，IME 进程内调用 | 延迟最低；无 IPC；与 Fcitx5 生态一致 | NDK 构建复杂；字典打包；许可与崩溃隔离 |
| B. libime 独立进程 | 单独 native 服务，通过 Binder 调用 | 崩溃隔离；可复用 | 首次延迟、IPC 复杂度、生命周期管理 |
| C. Kotlin 自研 / 轻量引擎 | 纯 JVM 拼音与词库 | 构建简单；无 NDK | 候选质量与词库维护成本高 |
| D. librime | Rime 引擎 | 成熟、可配置 | 体积/构建更重，与“倾向 libime”不一致 |

初判：**A（libime + JNI 同进程）** 优先评估；若崩溃隔离或内存成为问题，再考虑 B。C 只作为 libime 集成失败的退路。

### 10.3 二次讨论必须回答

1. libime 具体版本、依赖（Boost / fmt / CMake）、NDK 版本、ABI 是否只保留 arm64-v8a。
2. 拼音字典来源、体积、许可；是否需要 `libime-data` 全量数据。
3. 是否参考 / 复用 Fcitx5-Android 的 libime 构建与字典打包；其许可证与本项目是否兼容。
4. 同进程还是独立进程；线程模型与异步候选接口。
5. 候选页大小与展开容量（50/60）的配置方式。
6. 用户词典与自学习是否在 v1 开启。
7. 目标设备实测：冷加载、内存、按键到候选的 p95 延迟。
8. 许可证结论：libime 与字典的 LGPL / GPL 义务，APK 分发方式是否合规。

## 13. 验收标准

### 13.1 功能

- 字母层全部 26 键、数字/符号上滑、下滑在英/中模式下输出正确。
- 竖屏与横屏两档布局均正确，键位无遮挡；旋转后语言、主题、拼音状态保留。
- 横屏：左列 Alt/Ctrl/Shift、右列 删除/中英/确认；↑↓在左、←→在右；空格在 v/b 之间；候选面板 4×6；g 在右簇。
- 候选区：竖屏 5×140 行，无 `>`；横屏 4×6 格，无 `>`；点击候选上屏。
- 有拼音时确认键显示“展开”；展开后显示“返回”；竖屏展开仍为 14 行（拼音 1 + 常驻候选 1 + 9 行候选 + 功能 3）；横屏展开为拼音行 + 6 行候选；返回后恢复普通候选与字母键。
- 展开态竖屏保留底部功能行；横屏保留左右外列，确认键原位变“返回”。
- 符号层可翻页、可上屏；符号页不含键面可输入符号；页码显示在中/英键三行（`n` / `符` / `N`，全部 32px）。
- 中英切换、符号模式进入/退出、键面标签变化正确。
- Shift/Ctrl/Alt 的临时、锁定、取消、自动清除符合最终决策。
- 中文模式 Shift + 字母：无拼音时上屏大写；有拼音时忽略并保持拼音，不隐式提交。
- 方向键单击/长按；Tab 只在 a 上滑；删除长按连发；箭头无滑层。
- 空格在拼音中选首选；长按进转义；转义 `\n`/`\t`/`\u` 与扩展命令可执行；转义只显示缓冲，不显示预览/帮助。
- 确认键：有拼音普通态展开、展开态返回；无拼音换行/编辑器动作；长按收起键盘（有拼音时不响应）。
- 中文输入：连续拼音、候选、展开、选词、标点、退格、切语言、失焦清空；组字中不隐式上屏。
- 主题跟随系统 / 手动切换生效且持久化。

### 13.2 手势

- 单击、上滑、下滑、回中纠正、长按、连发、取消均符合第 4 节。
- 无标签方向为空滑动，释放时不输出任何字符。
- 快速连打不丢键、不串键；两指同时按键顺序正确。
- 符号页纵向滑动不会误上屏；候选点击不会误触键位。

### 13.3 系统

- 在至少一个普通文本框、一个浏览器输入框、一个终端类应用中可用。
- Esc / Tab / 方向键 / Ctrl 组合在支持的编辑器中正确；不支持时有明确降级，不崩溃。
- 密码框不学习、不记录；切换应用/输入框状态清空。
- 底部手势条不误触；键盘不被导航栏遮挡，横屏侧边导航栏也不例外。

### 13.4 排版与性能

- 720p 下键盘内所有文字 32px，无例外、不模糊；不使用 16/18/22/24/28。
- 键高 96px（3 个文字行）；所有列宽、行距、安全边距为整数。
- 竖屏 14 行连续：拼音 1 + 候选 1 + 主键 9 + 功能 3，行距 32px；纵向无额外按键间距；第四行文字居中。
- 横屏左右安全边距相等；各字母列宽相等、间距相等；候选格宽 ≥ 确认键宽。
- 横屏候选 6 行与按键 3+3 文字行逐行对齐；竖屏候选 5×140 与双列键网格对齐。
- 拼音只在文字后有背景色，不是整行；横屏拼音只在候选区上方。
- 按键反馈 ≤ 1 帧；预编辑 ≤ 100 ms；候选查询 p95 ≤ 50 ms（真机实测）。
- 连续输入 10 分钟无崩溃、无 ANR、无明显内存增长。
- 字典加载失败时有降级（英文仍可用），不阻塞键盘显示。

## 附录 D：Web 原型

- 路径：`webdemo/index.html`，内置 `fonts/unifont.otf`，无构建步骤。
- 运行：在 `webdemo/` 下执行 `python3 -m http.server 8000`，打开 `http://127.0.0.1:8000/`。
- 代码分层（原型冻结时的结构，可直接对照到原生实现）：
  - `js/data.js`：静态数据（键位定义、两方向键序、Mock 词库、过滤后的符号表、转义命令）。
  - `js/layout.js`：纯几何，`compute(orientation, safeInset)` 推出两方向全部坐标；不含 DOM 与业务状态。
  - `js/view.js`：视图，按 `model + metrics` 生成键盘、候选、拼音块、编辑器与日志；交互只通过 handlers 回传。
  - `js/input.js`：手势状态机（点按/滑动/长按/连发/符号翻页），只发语义意图。
  - `js/app.js`：状态与动作，串起 layout/view/input。
- 控制：竖/横屏预览、主题切换、示例 ni'hao、符号层、转义、事件日志、重置、全屏。安全边距固定，竖屏 32、横屏左右各 84，不提供运行时滑杆。
- 原型已覆盖：竖屏 14 行连续网格、9 行展开候选、横屏 4×6 候选面板与 10×6 展开候选、横屏拼音只在面板上方、确认键展开/返回、符号页过滤与中英键三行页码、转义 `\n`、双方向切换。
- 原型不覆盖：真实 InputConnection、按键事件、libime、慢刷新性能、长按/滑动的真机手感与圆角半径。
- 原型键盘内不显示模式、帮助、占位等额外提示；控制栏与事件日志在设备外，仅用于评审。
- 演示页在桌面浏览器会等比缩放；目标设备浏览器在 720p 下按 1:1 验收像素。
- 下一步：按 M2 在目标设备浏览器验收并冻结布局；然后进行 libime 后端二次讨论（M2.5）。
