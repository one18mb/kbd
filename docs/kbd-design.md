# KBD 输入法设计文档

> 版本：v1.1（Web 原型已产出；后端待二次讨论）  
> 日期：2026-11-06  
> 依据：用户提供的 `kbd.txt`（HTML 原型，10 列 × 4 行网格键盘）  
> 状态：交互已按原型评审修正；文中 **[已定]** 表示原型说明或已讨论确认，**[提案]** 表示待验证，**[待定]** 表示延后决定。  
> 已确认方向：路线一、竖屏 + 横屏、修饰键纯粘滞、候选条常驻（竖屏两行 / 横屏 2+3）、中文 Shift 直接上屏大写英文、确认键上屏原始字符、转义解析（`\n` `\t` `\u` + 可扩展命令）、全部内置 Unifont、竖横屏安全边距策略不同。  
> 横屏几何：键宽 76、外列 120、中间空缺 556−2R、候选面板 476−2R × 204（Web 原型 R=16 → 444×204）、符号区 20 列 × 3 行（60/页，页数按扁平列表自动计算）；R 实测后定。

## 0. 摘要与关键假设

本项目实现一款 Android 系统输入法，沿用原型中的 10 列 × 4 行网格键盘，支持中英文、符号页、修饰键、方向键与转义模式，中文输入后端倾向使用 libime。

关键假设：

| 项目 | 假设 |
| --- | --- |
| 设备 | Android，arm64-v8a（v8a），无物理键盘 |
| 屏幕 | 720 × 1604 竖屏 + 1604 × 720 横屏，两种方向都支持；竖屏为主形态，横屏为紧凑档 |
| 键盘基准 | 竖屏以 720 宽为设计基准；横屏使用独立的尺寸档，不按屏宽等比放大 |
| 字体 | 全部使用内置 Unifont（随 APK 打包；授权与字形覆盖需核实） |
| 形态 | 系统输入法（InputMethodService），不是独立编辑器 |
| 后端 | libime（倾向，开发前二次讨论定案） |
| 路线 | 路线一：先用 Web demo 冻结交互与布局，再进入原生开发 |

一句话方案：**原生 Kotlin 自定义 View 负责渲染与触摸状态机；布局与状态机数据化；libime 通过 JNI 提供拼音候选；Web demo 复用同一份布局 JSON 与交互规格，用来冻结体验。**

### 0.1 已确认决策

| 决策 | 结论 | 影响 |
| --- | --- | --- |
| 开发路线 | 路线一：Web demo 先行 | 先产出可评审的浏览器 demo，再写原生 |
| 屏幕方向 | 竖屏 + 横屏都支持，竖屏为主 | 需要两套尺寸档，Web demo 两个方向都要验收 |
| 修饰键 | 纯粘滞（sticky），不做按住组合 | 组合键通过“点修饰键 → 点目标键”完成；状态机较简单 |
| 转义模式 | 转义解析窗口：`\n`、`\t`、`\uXXXX` / `\u{...}` + 可扩展命令 | 空格执行转义，长空格退出；不是简单字面上屏 |
| 主要场景 | 日常聊天/笔记 + 终端/代码，两者兼顾 | 方向键、Esc/Tab、Ctrl/Alt 与中文候选都要验收 |
| 候选条 | 常驻；竖屏两行（预编辑 + 候选），横屏嵌入中间面板 2+3 | 无序号、无页码；展开箭头是 ASCII `>` |
| 中文模式 Shift | 无拼音缓冲时直接上屏大写英文；有拼音时不隐式上屏 | 有拼音时提示先上屏，避免隐式提交 |
| 拼音未上屏时按确认 | 上屏原始字符，不换行 | 空格负责选首选；确认键不选词、不执行换行 |
| 横屏布局 | 三行分栏 + 中间候选面板 | 键宽 76、外列 120、中间空缺 556−2R、面板 476−2R × 204 |
| 横屏符号 | 中间 20 列 × 3 行，60/页 | 扁平列表自动填充；无空格，与转义互斥；页数动态 |
| 安全边距 | 竖屏只上移，横屏只缩左右；按键无圆角 | 只适配物理屏幕四角；不裁切键面 |
| 中文符号 | 对齐 PC 搜狗中文标点方案 | 例如 k 上滑 `{`，不是 `《`；不是全部全角 |
| 拼音缓冲 | 单行 | 预编辑只占一行；不设固定字母上限 |
| 无标签滑动 | 空滑动，不输出 | 滑到无标签方向释放时不产生字符 |
| 字体 | 全部使用内置 Unifont | 键面、候选、预编辑统一；需核实授权 |
| 主题默认 | 跟随系统 | 用户可在设置覆盖 |
| 收起键盘 | 仅确认键长按 | 不额外增加收起按钮 |

### 0.2 原型中已明确的规则

- 10 列键位；3 行字母/功能行 + 1 行底部功能键。
- 每个字母键有“上滑 / 主键 / 下滑”三层，上下滑用纵向位移触发。
- Shift/Ctrl/Alt：短按切换状态并反色，长按锁定，再次按自身取消。
- 中英键：短按切换中/英，长按进入符号模式（键面显示“符”）。
- 符号层 5 页，每页 3 行 × 10 键，纵向滑动翻页。
- 第三行（z–m）没有下滑层。
- 方向键单击单步、按住连续移动；所有箭头**没有**上下滑绑定；Tab 在 a 上滑。
- 空格单击输入空格，长按进入转义模式；确认键单击换行，长按收起键盘。
- 转义模式提示延迟、上屏与退出（原型只打印到 console，未真正上屏）。
- 符号层原型固定 5 页；现改为扁平列表，按槽位自动换行填充。

### 0.3 本稿必须补齐的部分

原型的交互逻辑不完整，以下内容在原型中缺失或未定义，本稿给出设计：

1. 候选栏 / 编辑条（输入法核心 UI，原型完全没有）。
2. 字母键在非转义模式下没有上屏逻辑；修饰键没有实际作用。
3. 方向键长按连续移动未实现；a 上滑 Tab 未实现（箭头没有滑层）。
4. 删除键没有行为；确认键没有“编辑器动作”区分。
5. 转义模式的真正语义（`\n`/`\t`/`\u` 与扩展命令）未定义。
6. 滑动与长按的优先级、取消规则、多指处理、边界情况未定义。
7. 符号页无页码提示；符号键没有上屏动作。
8. 滑动到无标签方向时的行为未定义。
9. 中文输入时的标点、空格、删除、回车、切换语言规则未定义。
10. 主题切换停留在演示页，不是输入法设置。

## 1. 目标与非目标

### 1.1 目标

- 在 720 × 1604 竖屏与 1604 × 720 横屏上提供可日常使用的中英文输入；竖屏为主形态。
- 保留原型的“每键三层 + 功能键长按”的低层级交互，尽量减少切页。
- 让中文拼音输入具备：预编辑、候选、翻页、选词、上屏、退格、标点。
- 兼顾终端 / 代码场景：Esc、Tab、方向键、Ctrl/Alt 组合、转义模式。
- 交互状态可见：修饰键、中英、符号页、转义缓冲都有明确反馈。
- 低延迟、低内存、适合慢刷新屏幕（如墨水屏）。

### 1.2 非目标（永久不做）

以下内容全部不做，后续也不做：

- 手写、语音、表情、云候选、皮肤市场。
- 除中英以外的语言。
- 滑行输入（swipe typing）、九宫格、26 键传统布局。
- 用户自定义布局编辑器。
- 平板、折叠屏、自由窗口的额外适配（横屏已列入范围）。
- 联网、账号、同步。

## 2. 屏幕与尺寸模型

两种方向使用两套尺寸档：竖屏 10 列 × 4 行；横屏 3 行分栏。所有键宽、键高与间距均为整数，不出现小数。

### 2.1 竖屏档（720 × 1604）

| 名称 | 数值 | 说明 |
| --- | --- | --- |
| 屏宽 W | 720 | 竖屏设计基准 |
| 列数 | 10 | 每行固定 10 列 |
| 键间距 g | 4 | 水平与垂直间距 |
| 左右留白 | 2 | 每侧 2，键区宽 716 |
| 单列宽 u | **68** | 10×68 + 9×4 + 2×2 = 720 |
| 双列宽 | 2u + g = **140** | 空格 / 删除 / 确认 |
| 键高 h | 120 | 4 行等高 |
| 主/副字号 | 32 | 与原型一致 |
| 键盘本体高 | 4×120 + 3×4 = **492** | 不含候选条 |
| 候选条高 | **120** | 60 预编辑行 + 60 候选行 |
| 输入视图总高 | **612 + R** | R 为底部安全边距；R=16 → 628 |
| 应用区 | 1604 − 612 − R | R=16 → 976 |
| 候选/页 | **5 个 + `>`** | 不编号、无页码；`>` 为 ASCII 字符 |
| 安全边距 | 仅底部 R | 只上移，不缩左右；按键无圆角 |

### 2.2 横屏档（1604 × 720，三行分栏）

横屏为“左右分栏 + 中间候选面板”的三行布局。安全边距只缩左右、不上移：

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 屏宽 W | 1604 | 横屏 |
| 左右安全边距 R | 实测后定 | Web 原型取 16；键盘宽 `W_eff = 1604 − 2R` |
| 行数 | 3 | 字母三行 |
| 键高 h | **100** | 三行等高 |
| 行间距 g | 4 | |
| 键盘本体高 | 3×100 + 2×4 = **308** | 无底部安全边距 |
| 外列宽 F | **120** | 左列 Alt/Ctrl/Shift；右列 删除/中英/确认 |
| 字母/方向键宽 K | **76** | 每行 10 个字母/方向槽位 |
| 每行中间空缺 C | **556 − 2R** | R=16 → 524 |
| 候选面板 P | **476 − 2R × 204** | R=16 → 444×204 |
| 候选/页 | **5** | 2+3；无编号；下排末尾 ASCII `>` |
| 空格宽 | **556 − 2R** | 第三行中间，在 v 与 b 之间 |
| 输入视图总高 | **308** | 占 720 的 43%，应用区约 412 |
| 主 / 副字号 | 28 / 22 | |
| 符号区 | 20 列 × 3 行 | 中间可用宽度 `1356 − 2R`；键宽取整，余量居中 |

说明：

- 每行 10 个字母/方向槽位：R1 左 5 + 右 5，R2 左 6（↑ + a–g）+ 右 4，R3 左 5（↓ + z–v）+ 右 5（b–m + ← →）。
- 因 ↑ 占一个槽位，R2 左簇比 R1/R3 宽 80（76 + 4）；中间空缺随行错位 80。候选面板取 R1/R2 空缺交集，`P = 476 − 2R`；两侧各 80 余量（R1 左、R2 右）。R=0 时为 476，R=16 时为 444。
- 每行公式：`1604 − 2R = 2×120 + 12×4 + 10×76 + C`。
- 候选格：上排 2 个，下排 3 个 + `>`；格宽按面板宽度整数均分、余量分配到前几格，不出现小数。
- 中间面板常驻，跨 R1–R2；第三行中间是空格键（宽 C）。
- 横屏方向键与竖屏同构：↑/↓ 在左，←/→ 在右；所有箭头没有上下滑。
- 符号模式：左右外列保留，中间 `1356−2R` 宽全部为符号；20 列 × 3 行，键宽取整，余量居中。
- 按键无圆角；只有物理屏幕四角需要安全适配。竖屏只留底部 R，横屏只留左右 R；不裁切键面。
- 方向旋转时重建档位，保留语言、主题与未上屏拼音；取消进行中的触摸手势。**[提案]**
- 所有尺寸以基准比例换算为设备像素，字号用 sp；阈值（长按、滑动）使用同一物理距离，Web 原型真机校准。**[提案]**

## 3. 键盘布局

### 3.1 总览（字母层，竖屏）

```text
R1  [q] [w] [e] [r] [t] [y] [u] [i] [o] [p]
R2  [↑] [a] [s] [d] [f] [g] [h] [j] [k] [l]
R3  [↓] [z] [x] [c] [v] [b] [n] [m] [←] [→]
R4  [Shift] [Ctrl] [Alt] [中/英] [空格 ×2] [删除 ×2] [确认 ×2]
```

横屏的三行分栏布局见 3.8。

### 3.2 R1：数字 / 符号行

主键为字母；上滑为数字；下滑在英文模式为半角符号，中文模式按搜狗中文标点方案转换，**不是全部全角**。

| 列 | 主键 | 上滑 | 下滑（英） | 下滑（中） |
| --- | --- | --- | --- | --- |
| 1 | q | 1 | ! | ！ |
| 2 | w | 2 | @ | @ |
| 3 | e | 3 | # | # |
| 4 | r | 4 | $ | ￥ |
| 5 | t | 5 | % | % |
| 6 | y | 6 | ^ | …… |
| 7 | u | 7 | & | & |
| 8 | i | 8 | * | × |
| 9 | o | 9 | ( | （ |
| 10 | p | 0 | ) | ） |

数字上滑始终输出半角，不受中英模式影响。

### 3.3 R2：导航上 / 字母 a–l

| 列 | 主键 | 上滑（英） | 上滑（中） | 下滑（英） | 下滑（中） |
| --- | --- | --- | --- | --- | --- |
| 1 | ↑ | — | — | — | — |
| 2 | a | Tab | Tab | — | — |
| 3 | s | ~ | ～ | ` | ` |
| 4 | d | : | ： | ; | ； |
| 5 | f | " | “ | ' | ‘ |
| 6 | g | \| | \| | \ | 、 |
| 7 | h | + | + | = | = |
| 8 | j | _ | —— | - | - |
| 9 | k | { | { | [ | 【 |
| 10 | l | } | } | ] | 】 |

注：Tab 只在 `a` 上滑；所有箭头没有上下滑。`k/l` 上滑按搜狗中文标点保持 `{}`，不是 `《》`；`[`/`]` 中文下滑仍为 `【】`。

### 3.4 R3：导航下 / 字母 z–m / 左右方向

第三行没有下滑层。

| 列 | 主键 | 上滑（英） | 上滑（中） |
| --- | --- | --- | --- |
| 1 | ↓ | — | — |
| 2 | z | Esc | Esc |
| 3 | x | < | 《 |
| 4 | c | > | 》 |
| 5 | v | ? | ？ |
| 6 | b | , | ， |
| 7 | n | . | 。 |
| 8 | m | / | / |
| 9 | ← | — | — |
| 10 | → | — | — |

`x/c` 上滑中文为《/》；`m` 上滑保持 `/`，不再重复顿号；所有箭头没有滑层。

### 3.5 R4：功能行（竖屏）

| 列跨度 | 键 | 单击 | 长按 |
| --- | --- | --- | --- |
| 1 | Shift | 切换临时大写态；再按取消 | 锁定 / 解锁大写 |
| 1 | Ctrl | 切换临时 Ctrl 态；再按取消 | 锁定 / 解锁 |
| 1 | Alt | 切换临时 Alt 态；再按取消 | 锁定 / 解锁 |
| 1 | 中/英 | 切中/英；符号模式中则退出符号模式 | 进入符号模式（键面变“符”） |
| 2 | 空格 | 输入空格；拼音输入中选首选候选 | 进入转义模式；转义模式中退出 |
| 2 | 删除 | 退格；拼音输入中删拼音 | 连续退格 |
| 2 | 确认 | 换行 / 编辑器动作 | 收起键盘 |

横屏功能键不在底行，而是分布在左右外列，见 3.8。

### 3.6 符号层

- 符号数据是一维扁平列表，不固定每行内容；按当前方向槽位自动换行填充。
- 竖屏：3 行 × 10 列 = 30 个/页，替换 R1–R3；R4 保持不变；页数按列表长度自动计算。
- 横屏：除左右外列外，中间 3 行 × 20 列 = 60 个/页；页数按列表长度自动计算。
- 进入方式：长按中/英键；退出方式：符号模式中短按或长按中/英键。
- 翻页：在符号区域纵向滑动 ≥ 30 px，循环翻页。
- 页码显示：竖屏候选条预编辑行 `符号 1/N`；横屏中/英键 `符 1/N`。
- 符号键单击直接上屏；符号层没有上下滑层。
- 符号键在转义模式中可追加到转义缓冲。
- 符号清单按 PC 搜狗“符号大全”维护，原型内置常用扁平表；见附录 B。

### 3.7 候选 / 状态条（已定常驻）

原型没有候选栏，但作为输入法必须有，且已确认常驻。竖屏为两行，横屏嵌入中间面板。

| 方向档 | 位置 | 尺寸 | 结构 | 候选 / 页 |
| --- | --- | --- | --- | --- |
| 竖屏 | 键盘上方独立条 | 120 高 | 60 预编辑 + 60 候选 | 5 个 + ASCII `>` |
| 横屏 | 键盘中间面板 | 476−2R × 204（R=16 → 444×204） | 32 状态 + 2×84 候选 | 5 个（2+3）+ `>` |

竖屏示意（**只有两行，没有序号，没有页码图标**）：

```text
ni'hao
你好 尼好 拟好 你号 妮豪 >
```

- 第一行只显示预编辑串；模式（英/中/符/转义）由键面和应用标题显示，不加“中”前缀。
- 第二行显示 5 个候选，候选之间用空白分隔，末尾是标准 ASCII `>`；`>` 点击展开/下一页，不显示页码。
- 点击候选上屏，上屏后继续停留在当前语言。
- 候选翻页也可在候选区域横向滑动 ≥ 30 px；不显示页码。
- 无候选时第二行留空；横屏方向键固定在左右字母簇，不占用候选面板。
- 候选与预编辑统一使用内置 Unifont；字号竖屏 28–32、横屏 24；超长候选截断加省略号，点击仍上屏完整文本。
- 拼音预编辑只占一行；使用 `'` 分隔音节（由 libime 的分段结果决定）。
- 符号模式下第一行显示 `符号 1/N`，候选格留空；转义模式下第一行显示缓冲，第二行显示转义预览/命令帮助。

### 3.8 横屏布局（已定分栏）

```text
R1  [Alt] [q][w][e][r][t]    ┌ 状态 / 候选 1 2 ┐   [y][u][i][o][p] [删除]
R2  [Ctrl][↑][a][s][d][f][g] │ 候选 3 4 5      │   [h][j][k][l]     [中/英]
R3  [Shift][↓][z][x][c][v] [      空 格       ]   [b][n][m][←][→]    [确认]
```

- 左列自上而下：Alt、Ctrl、Shift（Shift 在左下角）。
- 右列自上而下：删除、中/英、确认（确认在右下角）。
- 方向键与竖屏同构：↑ 在 R2 左（Ctrl 之后）、↓ 在 R3 左（Shift 之后）、←/→ 在 R3 右（b–m 之后、确认之前）。
- 空格在 v 与 b 之间，宽 `556−2R`（第三行中间空缺；R=16 → 524）。
- 中间面板 `476−2R × 204` 位于 R1/R2 空缺的交集：顶部 32 状态行，下面 5 个候选格（2+3，格宽整数均分）。R=16 时面板 444×204。
- 面板两侧各留 80：R1 在左侧、R2 在右侧；面板不是固定 476，随安全边距收缩。
- 横屏只缩左右、不上移：左右各留 R，无底部安全边距；按键无圆角，只避免物理屏幕四角。
- 横屏符号层见 3.9。

### 3.9 横屏符号层（20 列 / 3 行）

- 除最左、最右两列（外列功能键）外，中间全部作为符号；3 行，20 列。
- 中间可用宽度 `1356−2R`；20 列键宽取整，余量居中。R=16 时约 62×100，3 行 × 20 = **60 个/页**。
- 符号是扁平列表，按 60/页自动填充；页数按列表长度计算，不固定 3 页。
- 20 列是宽屏下的常用整数解；最终列数与键宽可按 R 实测微调，但必须保持整数像素。
- 符号模式下没有空格键；需要空格时点中/英键退出符号模式。
- 横屏的符号模式与转义模式互斥：进入符号模式时退出转义模式（转义依赖空格上屏）。
- 页码显示在中/英键上：`符 1/N`；竖屏候选条显示 `符号 1/N`，同样按扁平列表计算页数。

## 4. 手势与状态机

### 4.1 阈值

| 手势 | 阈值 | 说明 |
| --- | --- | --- |
| 长按 | 500 ms | 与原型一致 |
| 滑动判定 | 纵向 ±25 px | 进入上滑 / 下滑态 |
| 滑动回中 | 纵向 ±12 px | 回中后取消滑动，回到待定态（滞回，允许纠正） |
| 方向键 / 删除连发 | 按住 500 ms 后每 60 ms 一次 | 首次动作在 500 ms 时触发 |
| 符号页翻页 | 纵向 ≥ 30 px | 纵向滑动优先翻页，不触发符号上屏 |
| 候选翻页 | 横向 ≥ 30 px | 候选行内 |
| 点按 | 释放时仍未进入滑动 / 长按 | 执行主键动作 |

阈值单位：Web demo 使用 CSS px；原生使用 dp，并按目标设备手感校准。键高为竖屏 120 / 横屏 100；若横屏 25 px 滑动过于敏感，可降到 20–22 px。**[待定]**

### 4.2 一次触摸的完整判定

1. **按下**：命中键位，显示按下态（反色），启动 500 ms 长按计时器。
2. **移动**：
   - 仍为待定态时，纵向位移达到 ±25 px 且该方向有标签 → 进入上滑 / 下滑态，取消长按计时器，居中显示该方向标签。
   - 已进入滑动态后，回中到 ±12 px 内 → 回到待定态，可重新选择方向。
   - 纵向位移未达阈值 → 保持待定态；横向抖动不触发任何动作。
   - 该方向没有标签（例如第三行下滑）→ 进入“空滑动”态：键面显示空白，释放时不上屏任何字符；回中后可取消空滑动并按主键处理。**[已定]**
3. **长按**：
   - 待定态持续 500 ms → 执行长按动作（修饰键锁定、空格进转义、中/英进符号、确认收起键盘）。
   - 方向键 / 删除 → 进入连发态，立即执行一次，之后每 60 ms 一次。
   - 字母键没有长按动作 → 继续待定，释放时照常上屏。
   - 长按一旦触发，滑动判定失效；连发过程中移动手指不改变动作。
4. **释放**：
   - 待定态 → 主键动作。
   - 滑动态 → 对应方向标签上屏。
   - 长按 / 连发态 → 结束动作，不再执行点按。
5. **取消**：
   - 触摸被系统打断（来电、通知、多任务）→ 取消本次手势，不产生输入。
   - 指针移出键盘区域较远（超过一行的距离）→ 取消本次手势。**[提案]**
   - 同一指针只属于一个键；手指从 A 滑到 B 不会触发 B。

### 4.3 多指

- 每个指针独立判定，最多同时跟踪 2 个指针。
- 两个字母键同时按下时，按释放顺序上屏；先释放者先上屏。
- 纯粘滞模型下不做按住组合；第二个指针按键独立上屏，修饰态按粘滞状态消耗。
- 第 3 个及以上指针忽略，避免误触。

### 4.4 修饰键状态机

原型语义（基线，**[已定]**）：

| 状态 | 进入 | 表现 | 退出 |
| --- | --- | --- | --- |
| off | 初始 | 正常配色 | — |
| temp | 短按一次 | 反色 | 再次短按；或下一个非修饰键上屏后自动清除 |
| locked | 长按 500 ms | 反色（建议加小锁标记） | 再次短按 |

说明：

- 临时态作用于“下一个键”；锁定态持续作用于后续键，直到再次点按解锁。
- 字母、符号、方向、删除、确认、空格都会消耗临时修饰态；修饰键自身不消耗。
- Shift 额外控制字母显示大小写。
- Ctrl/Alt 不改变字母大小写，只改变自身反色状态与输出（见第 7 节）。
- 锁定态不会被自动清除，只能再次点按解锁。
- 进入转义模式时清除所有修饰态。**[提案]**

已确认采用纯粘滞（sticky）语义：不支持“按住修饰键 + 另一指按键”的 chord；组合键通过先点修饰键、再点目标键完成。长按仍用于锁定。若后续需要 chord，作为独立版本再评估，不进入 v1。

### 4.5 语言、图层与转义

- 语言状态：`EN` / `ZH`，默认 `EN`（原型默认）。
- 图层状态：`letters` / `symbols`。
- 符号页：页数按扁平列表和当前槽位自动计算；竖屏 30/页，横屏 60/页，循环。
- 转义状态：`off` / `on`，缓冲最多 16 个字符（含开头的 `\`）。
- 互斥规则：
  - 符号模式与转义模式：竖屏可共存（符号键可追加进转义缓冲）；横屏互斥，进入符号模式时退出转义模式（符号模式无空格键）。
  - 有未上屏拼音时，进入符号模式 / 切语言 / 转义 / 方向移动都**不隐式提交**，提示先上屏。
  - 收起键盘 / 切换输入框 / 失焦时，清空拼音、转义缓冲、临时修饰态；保留中英选择与主题。**[提案]**

## 5. 各键行为规格

### 5.1 字母键

| 条件 | 行为 |
| --- | --- |
| 英文模式，主键 | 上屏对应字母；Shift 临时/锁定则大写 |
| 中文模式，主键 | 追加到拼音缓冲，更新候选 |
| 中文模式，Shift 生效 | 无拼音缓冲时直接上屏大写 ASCII；有拼音缓冲时不隐式上屏，提示先上屏 |
| 上滑 / 下滑 | 上屏对应层标签；中文模式按搜狗标点映射，不是全部全角 |
| Ctrl / Alt 生效 | 转换为带 meta 的按键事件，不追加拼音（见第 7 节） |
| 方向无标签 | 空滑动，不输出任何字符（已定） |

### 5.2 功能键

| 键 | 单击 | 长按 | 备注 |
| --- | --- | --- | --- |
| Shift | 切换临时大写 | 锁定 | 中文模式下直接上屏大写英文（见 5.1） |
| Ctrl | 切换临时 Ctrl | 锁定 | 组合输出见第 7 节 |
| Alt | 切换临时 Alt | 锁定 | 组合输出见第 7 节 |
| 中/英 | 切语言；符号模式中退出 | 进入符号模式 | 键面显示当前语言 `英`/`中`，符号模式显示 `符` |
| 空格 | 拼音中选首选；否则上屏空格 | 进入转义模式 | 转义模式中单击执行转义，长按退出 |
| 删除 | 退格；拼音中删拼音；转义中删缓冲末字符 | 连续删除 | 拼音删空后再退格 |
| 确认 | 拼音中上屏原始字符，不换行；无拼音时执行编辑器动作 / 换行 | 收起键盘 | 空格负责选首选，确认不选词 |
| ↑ | 光标上移一步 | 连续上移 | 竖屏 R2 左；横屏 Ctrl 之后；无滑层 |
| ↓ | 光标下移一步 | 连续下移 | 竖屏 R3 左；横屏 Shift 之后；无滑层 |
| ← | 光标左移一步 | 连续左移 | 竖屏 R3 右；横屏 b–m 之后；无滑层 |
| → | 光标右移一步 | 连续右移 | 竖屏 R3 右；横屏 b–m 之后；无滑层 |

### 5.3 符号键

- 单击上屏符号。
- 符号模式下纵向滑动翻页；滑动一旦越过 30 px，取消本次按键上屏。
- 横屏符号键占满左右外列之间的 20 列 × 3 行；页码显示在中/英键上。
- 转义模式中追加到缓冲。
- 修饰键对符号键的作用：建议忽略 Ctrl/Alt，Shift 不影响符号。**[提案]**

### 5.4 候选键

- 单击上屏该候选，结束本轮拼音。
- 候选翻页不改变拼音缓冲。
- 点击区域：竖屏约 130 × 60；横屏格宽按面板宽度整数均分（R=16 时上排约 220×84、下排约 136×84）；均满足触控目标要求。

### 5.5 转义模式（已定：转义解析窗口）

**进入 / 退出**

- 长按空格进入。若中文有未上屏拼音，先上屏（不隐式提交；提示先上屏）。
- 单击空格：解析并执行缓冲，退出。
- 长按空格：退出，不执行。
- 收起键盘 / 失焦：退出并清空缓冲。
- 缓冲太长、非法转义：保持窗口并提示，不上屏。

**缓冲**

- 初始为 `\`；最多 16 个字符（含 `\`），足够 `\u{10FFFF}`。
- 可追加：字母（小写）、数字、符号层符号、各键主/滑层中的可打印字符。
- 不追加：方向键、Tab/Esc 键本身、修饰键、中/英、确认、删除、空格。
- 删除键：删除缓冲末字符；退到只剩 `\` 后不再删除。长按删除连续删除。
- 符号模式可共存（竖屏）；横屏符号模式与转义互斥。
- 修饰键状态在进入时清空，转义模式中忽略修饰键。

**解析（可扩展）**

| 转义 | 结果 |
| --- | --- |
| `\n` | 换行（插入换行字符；与确认键“可能一样”但语义独立） |
| `\t` | 制表（插入 Tab 字符） |
| `\u4e2d` | U+4E2D → `中`（4 位十六进制） |
| `\u{1F600}` | 支持 1–6 位十六进制、全 Unicode |
| `\s` | 打开设置（命令扩展点，原型中提示设置入口） |
| `\j` | 简繁切换（命令扩展点，原型中提示预留） |
| `\\` | 反斜杠本身 |

**显示 / 输出**

- 候选条第一行显示缓冲（如 `\u4e2d`），第二行显示 `→ 中`、`→ 换行` 或命令帮助。
- 空格键主标签显示缓冲；长缓冲自动缩小字号。
- 转义结果按字符/动作执行，不是把 `\n` 两个字符原样上屏。
- 需要真正的键盘事件时，仍使用 Esc/Tab/方向键与 Ctrl/Alt；转义模式用于字符与自定义操作。

## 6. 中文输入流程（libime）

### 6.1 状态

```text
Idle ──字母──> Composing(拼音, 候选) ──空格(首选) / 确认(原始字符) / 候选点击──> Idle
                  │
                  ├─ 删除：退一个拼音字母
                  ├─ 标点 / 方向 / 切语言 / 符号 / 转义：忽略并提示“先上屏拼音”
                  └─ 失焦：清空
```

### 6.2 上屏规则

**只有三种显式提交：空格上屏首选词、确认上屏原始字符、点击候选上屏候选词。其他操作不隐式提交。**

| 操作 | 有拼音缓冲 | 无拼音缓冲 |
| --- | --- | --- |
| 字母 | 追加拼音 | — |
| Shift + 字母 | 不隐式上屏，提示先上屏 | 上屏大写 ASCII |
| 空格 | 上屏候选 1；若无候选，上屏原始拼音 | 上屏半角空格 |
| 标点（上/下滑） | 忽略并提示先上屏 | 上屏标点 |
| 删除 | 删除拼音末字母 | 退格 |
| 确认 | 上屏原始字符，不换行、不执行动作 | 执行编辑器动作 / 换行 |
| 方向键 | 忽略并提示先上屏 | 移动光标 |
| 切语言 | 忽略并提示先上屏 | 切换 |
| 候选点击 | 上屏该候选 | — |

其他规则：

- 拼音缓冲**单行**：不设固定字母上限，预编辑只占一行；超出单行宽度时截断/横向滚动，不换行、不自动提交。
- 无有效候选时（如 `zzzz`），候选列表退化为原始拼音；空格上屏原始拼音，不会卡住。
- 空格负责选首选；确认键不选词，把原始字符上屏，且本轮不换行；再次按确认（无拼音时）才执行换行 / 编辑器动作。
- 候选分页由 libime 返回；每页 5 个，横屏为 2+3 排列；不显示页码，末尾 ASCII `>` 翻页。
- 预编辑与候选使用同一份拼音串；避免显示与上屏不一致。
- 中文标点按搜狗中文标点映射（例如 k 上滑 `{` 而不是 `《`），不是全部全角。
- 数字始终半角。
- 英文模式不产生拼音预编辑，直接 `commitText`。

### 6.3 与 libime 的边界

本稿只约定前端需要的接口语义，具体库版本、字典与线程模型在二次讨论中定案：

```text
EngineInput: 拼音串（无空格）
EngineOutput:
  preedit    分段后的拼音显示串（可选）
  candidates 候选文本列表（每项可带注释）
  page       当前页 / 总页数
  hasMore    是否还有下一页

API:
  reset()
  update(pinyin: String) -> Result
  selectCandidate(index: Int) -> String
  nextPage() / prevPage()
```

- 候选生成应可异步；用递增的 generation id 丢弃过期结果。
- 若查询在主线程可稳定在预算内，可同步调用；先测再定。
- 用户词频 / 自学习 v1 不做；若 libime 自带用户词典，可在 v1.1 打开。**[待定]**

## 7. 修饰键与按键事件

Android 输入法不能保证所有编辑器都接受任意按键事件，因此需要分层处理：

| 组合 | 输出方式 | 说明 |
| --- | --- | --- |
| Shift + 字母 | `commitText` 大写字母 | 最可靠 |
| Ctrl / Alt + 字母 | `sendKeyEvent(KeyEvent with META_CTRL/ALT)` | 终端、部分编辑器支持；普通 EditText 可能忽略 |
| Ctrl / Alt + 方向 / 删除 / Esc / Tab | `sendKeyEvent` 带 meta | 终端类应用的主要场景 |
| 无修饰的 Esc / Tab / 方向 | `sendKeyEvent`（DOWN + UP） | 不走 `commitText` |
| 回车 | `performEditorAction` 或 `commitText("\n")` | 按编辑器能力选择 |
| 退格 | `deleteSurroundingTextInCodePoints(1, 0)`；失败回退 `sendKeyEvent(KEYCODE_DEL)` | API 24+ |
| 文本 / 符号 / 空格 | `commitText` | 常规路径 |

注意：

- `Ctrl+C` 等组合在普通文本框中可能无效，这是 Android IME 的系统限制，不是键盘 bug。
- 转义模式是解析窗口（见 5.5），用于 `\n`/`\t`/`\u` 与自定义命令，不能替代真正的控制字符；若目标场景是终端，应优先使用 Esc/Tab/方向键与 Ctrl/Alt 组合。
- 修饰键 + 滑动符号的组合按 `KeyCharacterMap` 尽力转换；无法映射时忽略修饰并上屏字符。**[提案]**

## 8. 系统集成

- 组件：`InputMethodService` + 自定义 `InputView` + 候选/状态条（可合并在同一个自绘 View 中）。
- 输入视图尺寸：宽度 match_parent；竖屏高度 = 键盘 + 独立候选条 + 底部安全边距 R；横屏高度 = 三行键盘（无底部边距），左右各留安全边距 R，候选面板内嵌。
- `onEvaluateFullscreenMode()` 返回 `false`，避免横屏 / 小屏时进入全屏提取模式。
- `onStartInput` / `onFinishInput` / `onStartInputView` 负责：读取 `EditorInfo`、重置状态、决定确认键行为。
- 密码 / 敏感输入框：不记录、不学习；候选仍可用。
- 输入法切换、返回键、通知打断：清空当前手势与拼音。
- 底部系统手势冲突：用 `setSystemGestureExclusionRects` 排除空格/删除/确认所在区域。
- 硬件键盘存在时仍显示软键盘；不做物理键盘映射。
- 主题：默认跟随系统深/浅色；提供“始终深色 / 始终浅色”设置。原型中的切换按钮不属于键盘，放到设置页。
- 触感反馈：可选，默认开启短震动（约 20 ms）；不提供按键音。
- 收起键盘：确认键长按；是否额外提供状态条“收起”按钮见 D14。
- 输入视图高度固定，不因候选有无而变化；避免整屏重排与墨水屏闪屏。

## 9. 前端实现架构

### 9.1 原生端（已选）

- 语言：Kotlin；单一 IME APK + 设置页。
- 渲染：一个自定义 `View` 自绘全部键位与候选条，不创建几十个子 View；只重绘脏区。
- 布局与状态分离：
  - `layout.json`：键位、宽度、各层标签、动作 id、长按动作。
  - `GestureResolver`：纯逻辑手势判定（可单元测试）。
  - `KeyboardState`：语言、图层、符号页、修饰态、转义缓冲。
  - `Renderer`：把状态画到 Canvas。
  - `ImeController`：把动作转成 `InputConnection` 调用。
  - `EngineBridge`：JNI ↔ libime。
- 键位命中测试与触摸跟踪放在容器层，避免原型中“每个键各自监听”带来的跨键、多指、touchend 归属问题。
- 字体：全部使用内置 Unifont（TTF/OTF 随 APK 打包）；键面、候选、预编辑统一。Unifont 在像素对齐时锐利、字符集全；需核实授权与目标字符覆盖。
- 性能预算（待真机验证）：
  - 按下反馈 ≤ 1 帧；
  - 拼音预编辑更新 ≤ 100 ms；
  - 候选查询 p95 ≤ 50 ms；
  - 键盘冷启动可交互 ≤ 1 s，字典后台加载不阻塞输入；
  - 常驻内存目标 ≤ 150 MB（含字典）。

### 9.2 Web demo（路线一，已选）

- 技术：TypeScript + Vite，无框架；Pointer Events + `touch-action: none`；同一页面支持 720 × 1604 与 1604 × 720 两个视口。
- 方向档：竖屏按 2.1 节尺寸；横屏按 2.2 / 3.8 节三行分栏；旋转 / 改变窗口时实时切换档位，保留语言、主题与拼音状态。
- 复用：与原生端共用 `layout.json`；交互规则按本文档实现；用 MockEngine 模拟 libime 的候选、分页、上屏。
- 页面包含：可输入的文本框、候选条、键盘、设置（主题）。
- 目标：在目标设备浏览器上验证两种方向的手感、滑动阈值、候选条可读性、转义模式；冻结布局与交互规格。
- 不追求：真实 JNI、系统输入法行为、墨水屏刷新性能；这些必须原生阶段验证。
- 退出标准：第 13 节验收项在 Web 端可通过（除系统集成项），竖屏与横屏都通过，布局 JSON 冻结，开放问题收敛。

### 9.3 数据驱动示例

```json
{
  "version": 1,
  "grid": { "cols": 10, "keyHeight": 120, "gap": 4 },
  "rows": [
    {
      "keys": [
        {
          "id": "q",
          "width": 1,
          "main":  { "en": "q", "zh": "q" },
          "up":    { "en": "1", "zh": "1" },
          "down":  { "en": "!", "zh": "！" },
          "action": "letter"
        }
      ]
    }
  ]
}
```

动作类型建议：`letter`、`digit`、`symbol`、`nav`、`tab`、`esc`、`modifier`、`lang`、`space`、`backspace`、`enter`、`candidate`。每个键只描述“是什么”，输出与状态转换由状态机决定。

`layout.json` 顶层按 `orientation` 提供两套 profile：`portrait`（10 列 × 4 行 + 独立候选条）与 `landscape`（3 行分栏 + 中间候选面板）；两套 profile 共用动作 id 与状态机。

## 10. 后端架构选型（二次讨论）

> 本节只列议题与初判，不在本稿定案。开发前必须单独讨论一次。

### 10.1 需求

- 中文拼音候选质量可用，支持连续输入、分词、翻页。
- 冷启动与每次按键延迟可接受（目标设备）。
- 字典体积、内存占用可控；离线可用。
- arm64-v8a 可直接集成；构建链可维护。
- 许可允许分发（开源或闭源需分别评估）。
- 用户词频 / 自学习可扩展（v1.1）。

### 10.2 候选方案

| 方案 | 描述 | 优点 | 风险 |
| --- | --- | --- | --- |
| A. libime + JNI 同进程 | 把 libime 编译为 arm64-v8a 动态库，IME 进程内调用 | 延迟最低；无 IPC；与 Fcitx5 生态一致 | NDK 构建复杂；字典打包；许可与崩溃隔离 |
| B. libime 独立进程 | 单独 native 服务，通过 Binder 调用 | 崩溃隔离；可复用 | 首次延迟、IPC 复杂度、生命周期管理 |
| C. Kotlin 自研 / 轻量引擎 | 纯 JVM 拼音与词库 | 构建简单；无 NDK | 候选质量与词库维护成本高 |
| D. librime | Rime 引擎 | 成熟、可配置 | 体积/构建更重，与“倾向 libime”不一致 |

初判：**A（libime + JNI 同进程）** 优先评估；若崩溃隔离或内存成为问题，再考虑 B。C 只作为 libime 集成失败的退路。

### 10.3 二次讨论必须回答

1. libime 具体版本、依赖（Boost / fmt / CMake）、NDK 版本、ABI 是否只保留 arm64-v8a。
2. 拼音字典来源、体积、许可；是否需要 `libime-data` 全量数据。
3. 是否参考 / 复用 Fcitx5-Android 的 libime 构建与字典打包；其许可证与本项目是否兼容。
4. 同进程还是独立进程；线程模型与异步候选接口。
5. 用户词典与自学习是否在 v1 开启。
6. 目标设备实测：冷加载、内存、按键到候选的 p95 延迟。
7. 许可证结论：libime 与字典的 LGPL / GPL 义务，APK 分发方式是否合规。

## 13. 验收标准

### 13.1 功能

- 字母层全部 26 键、数字/符号上滑、下滑在英/中模式下输出正确。
- 竖屏与横屏两档布局均正确，键位无遮挡；旋转后语言、主题、拼音状态保留。
- 横屏：左列 Alt/Ctrl/Shift（Shift 左下）、右列 删除/中英/确认（确认右下）、↑↓在左、←→在右、空格在 v/b 之间、中间候选面板 476−2R × 204（2+3）。
- 候选条：竖屏两行（预编辑 + 5 个候选 + ASCII `>`），无序号、无页码；横屏 2+3 无编号；翻页与点选正确。
- 符号层可翻页、可上屏、页码正确；页数按扁平列表动态，不固定 5/3 页。
- 中英切换、符号模式进入/退出、键面标签变化正确。
- Shift/Ctrl/Alt 的临时、锁定、取消、自动清除符合最终决策。
- 中文模式 Shift + 字母：无拼音时上屏大写；有拼音时提示先上屏，不隐式提交。
- 方向键单击/长按；Tab 只在 a 上滑；删除长按连发；横屏 ↑↓在左、←→在右；箭头无滑层。
- 空格在拼音中选首选；长按进转义；转义 `\n`/`\t`/`\u` 与扩展命令可执行。
- 确认键：拼音中上屏原始字符且不换行；无拼音时执行编辑器动作 / 换行；长按收起键盘。
- 中文输入：连续拼音、候选、翻页、选词、标点、退格、切语言、失焦清空；组字中不隐式上屏。
- 主题跟随系统 / 手动切换生效且持久化。

### 13.2 手势

- 单击、上滑、下滑、回中纠正、长按、连发、取消均符合第 4 节。
- 无标签方向为空滑动，释放时不输出任何字符。
- 快速连打不丢键、不串键；两指同时按键顺序正确。
- 符号页纵向滑动不会误上屏；候选横向滑动不会误选。

### 13.3 系统

- 在至少一个普通文本框、一个浏览器输入框、一个终端类应用中可用。
- Esc / Tab / 方向键 / Ctrl 组合在支持的编辑器中正确；不支持时有明确降级，不崩溃。
- 密码框不学习、不记录；切换应用/输入框状态清空。
- 底部手势条不误触；键盘不被导航栏遮挡，横屏侧边导航栏也不例外。

### 13.4 性能与稳定性

- 按键反馈 ≤ 1 帧；预编辑 ≤ 100 ms；候选查询 p95 ≤ 50 ms（真机实测）。
- 连续输入 10 分钟无崩溃、无 ANR、无明显内存增长。
- 字典加载失败时有降级（英文仍可用），不阻塞键盘显示。
