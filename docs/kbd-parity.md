# KBD 原型对齐真值表（v1，供重写）

> 唯一真值来源：`webdemo/`（`data.js`、`layout.js`、`view.js`、`input.js`、`app.js`、`styles.css`）。
> 本文只描述**状态与结果**，不描述实现方式。滚动效果按你先前的要求单列，不纳入对齐。
>
> **前端已冻结（2026-11-08）**：除第 6 节 D1–D12 记录在案的平台差异外，显示与交互以本文为准；新需求先写进本文再改代码。

---

## 1. 状态模型

| 状态 | 取值 | 说明 |
| --- | --- | --- |
| `lang` | `zh` / `en` | 决定字母是走拼音还是直接上屏；决定上下滑标签取中文形态还是英文形态 |
| `layer` | `letters` / `symbols` | 只影响主键区渲染 |
| `escape` | bool | 转义态 |
| `escapeBuffer` | 字符串，初值 `\`，上限 16 字符 | 转义缓冲 |
| `mods.shift/ctrl/alt` | `{active, locked}` | 纯粘滞 |
| `composing` | 字符串 | 原始按键串（小写字母），上限 40 |
| `candidates` | 列表 + `preedit` | 由 composing 派生；`expanded` 由用户切换 |
| `expanded` | bool | 仅在 composing 时有效 |
| `symbolPage` | 整数 | 符号层页码 |
| `keyboardVisible` | bool | 长按确认可收起 |

派生：
- `composing != ''` 时才渲染候选；
- `expanded` 在 composing 清空时强制为 false。

## 2. 动作 × 状态 真值表

记号：**执行**＝改变状态/上屏；**拦截**＝什么都不发生（原型里提示元素缺失，`showToast` 为空操作，故全部静默）；**清修饰**＝清除所有 `active && !locked` 的修饰键。

### 2.1 点按：修饰键（shift / ctrl / alt）

| 当前 | 结果 |
| --- | --- |
| `locked` | `active=false, locked=false` |
| 其他 | `active = !active, locked=false` |

### 2.2 点按：中英键 lang

| 当前 | 结果 |
| --- | --- |
| `layer=symbols` | 退出符号层（`layer=letters`，清修饰） |
| `composing` | 拦截 |
| 其他 | `lang` 取反；清修饰 |

### 2.3 点按：空格

| 当前 | 结果 |
| --- | --- |
| `escape` | 执行转义（见 2.11） |
| `composing` | 上屏首选；清修饰 |
| 其他 | 插入一个空格；清修饰 |

### 2.4 点按：删除

| 当前 | 结果 |
| --- | --- |
| `escape` 且缓冲长度 > 1 | 缓冲去掉末字符 |
| `composing` | `composing` 去掉末字符（可减到空） |
| 其他 | 删除编辑器光标前一个字符 |
| 以上全部 | 末尾清修饰（含 escape 分支） |

### 2.5 点按：确认

| 当前 | 结果 |
| --- | --- |
| `escape` | 拦截 |
| `composing` | `expanded` 取反；清修饰 |
| 其他 | 插入换行；清修饰 |

### 2.6 点按：方向键（↑↓←→）

| 当前 | 结果 |
| --- | --- |
| `composing` 或 `escape` | 拦截；清修饰 |
| 其他 | 移动编辑器光标（原型为自绘行列移动，见 6.D2）；清修饰 |

### 2.7 点按：字母

| 当前 | 结果 |
| --- | --- |
| `escape` | 缓冲追加该字母（小写）；若 shift 处于 active 则清修饰 |
| `ctrl` 或 `alt` active | 原型：拦截（仅记录组合键）；原生：未组词时发带修饰态的 KeyEvent（见 D9）；末尾清修饰 |
| `lang=zh` 且 `composing` | shift active → 拦截＋清修饰；否则 `composing += 字母`（小写） |
| `lang=zh` 且非 composing 且 shift | 插入大写字母；清修饰 |
| `lang=zh` 且非 composing | `composing += 字母` |
| `lang=en` | 插入 `shift ? 大写 : 原字母`；清修饰 |

补充：`composing` 长度达 40 时不再追加（原型有该上限）。

### 2.8 长按

触发时长 400ms；仅当该键定义了 `long` 或 `repeat` 才进入长按流程。

| 键 | 结果 |
| --- | --- |
| shift / ctrl / alt | `active=true, locked=true` |
| 空格 | `escape` 已开 → 退出转义；`composing` → 拦截；否则进入转义（缓冲重置为 `\`，清修饰） |
| 中英 | `layer=symbols` → 退出符号层；否则进入符号层（`composing` 时拦截）。进出符号层都清修饰 |
| 确认 | `composing` → 拦截；否则收起键盘 |
| 删除 / 方向键 | 进入连发（见 2.9） |

### 2.9 连发（60ms）

| 键 | 每次触发 |
| --- | --- |
| 删除 | 同 2.4 |
| 方向键 ← → | `composing` 或 `escape` 时不动；否则移动光标一格 |
| 方向键 ↑ ↓ | 不连发（原型 `repeatKey` 只处理左右） |

### 2.10 上滑 / 下滑（松手时执行）

| 目标标签 | 当前 | 结果 |
| --- | --- | --- |
| 有 | `escape` | 单字符 → 追加缓冲；`Tab`/`Esc` → 拦截；其他（含 `……` 等多字符标点）→ 追加缓冲 |
| 有 | `layer=symbols` | 插入该字符 |
| 有 | `composing` | 拦截；清修饰 |
| 有 | 其他 | `Tab` → 插入制表；`Esc` → 发送 ESC（D3）；其余 → 插入该字符；ctrl/alt 按下时改发带修饰态的 KeyEvent（D9）；清修饰 |
| 无（空滑动） | 任意 | 拦截；清修饰 |

补充：中文 `f` 键特殊——上滑双引号循环 `“`→`”`→`“`，下滑单引号循环 `‘`→`’`→`‘`，标签随之变化（D11）；英文模式仍是 `"` / `'`。

### 2.11 转义执行（空格点按触发）

判定 `body = buffer[1:]`：

| body | 结果 |
| --- | --- |
| 空 | 仅帮助信息，不执行；随后退出转义 |
| `n` | 插入换行 |
| `t` | 插入制表 |
| `s` | 无可见效果（原型的“设置”动作只记日志） |
| `j` | 无可见效果（原型的“简繁”动作只记日志） |
| `hp` | 打开命令面板（不上屏），候选区显示 `简 sc / 繁 tc / 暗 dk / 亮 lt`（D12） |
| `sc` | 简体输出（词典本身即简体） |
| `tc` | 繁体输出（候选与上屏经平台简→繁转换，见 D12） |
| `dk` | 暗皮肤（覆盖系统主题） |
| `lt` | 亮皮肤（覆盖系统主题） |
| `au` | 恢复自动（跟随系统深浅色）；以上效果持久化 |
| `u` + 4 位十六进制 | 插入该码点字符 |
| `u{1–6 位十六进制}` | 同上 |
| 非法码点 / 其他 `u…` / 未知 | 不插入 |
| `\` | 插入一个 `\` |
| 以上任意 | 最后都退出转义（`escape=false, buffer='\'`） |

### 2.12 符号层点按

| 当前 | 结果 |
| --- | --- |
| `escape` | 追加缓冲 |
| 其他 | 插入该符号；清修饰 |

### 2.13 点按候选

| 当前 | 结果 |
| --- | --- |
| 有候选 | 该候选上屏；`composing` 清空；`expanded=false`；清修饰 |

### 2.14 选中后状态

上屏后：`composing=''`、`preedit=''`、`candidates=[]`、`expanded=false`；重新渲染。

## 3. 手势判定（input.js）

| 规则 | 数值/条件 |
| --- | --- |
| 同时手指数 | 已有 1 个会话时，第二指忽略 |
| 长按触发 | 400ms，且键定义了 `long` 或 `repeat` |
| 连发间隔 | 60ms |
| 上滑进入 | 位移 ≤ −25px |
| 下滑进入 | 位移 ≥ +25px |
| 滑出上 | 位移 > −12px → 回到待定 |
| 滑出下 | 位移 < +12px → 回到待定 |
| 滑上↔滑下切换 | 上滑态位移 ≥ +25 → 切下滑；下滑态位移 ≤ −25 → 切上滑 |
| 符号层翻页判定 | 位移绝对值 ≥ 30px（本次改为按行滚动，见 6.D4） |
| 松手判定 | 待定态 → 执行点按；滑动态 → 执行目标；空目标 → 空滑动 |
| 空符号格 | 不渲染、不可点，只可作为翻页起点 |
| 按下态视觉 | 手指按下即反色；滑动时仍保持反色 |

## 4. 显示真值（标签与样式）

### 4.1 标签

| 键 | 常态 | 特殊态 |
| --- | --- | --- |
| 字母 | `id` | shift active → 大写 |
| 上/下滑 | 无则空 | `lang=zh` 取中文形态，`lang=en` 取英文形态 |
| shift / ctrl / alt | 固定 `Shft` / `Ctrl` / `Alt` | — |
| lang | `zh→中`，`en→英` | `layer=symbols` → `符`，上=当前页，下=总页数 |
| 空格 | `空格` | `escape` → `\` |
| 删除 | `删除` | — |
| 确认 | `确认` | `composing` → `展开`；`composing && expanded` → `返回` |
| 方向键 | `↑ ↓ ← →` | — |

### 4.2 键态样式

| 键态 | 底色 | 主字 | 副字（上/下） |
| --- | --- | --- | --- |
| 常态 | `key` | `text` | `sub` |
| 按下（待定） | `text` | `key` | 隐藏 |
| 滑动中（有目标） | `text` | `key` | 只显示目标，居中整键 |
| 滑动中（空目标） | `text` | — | 全部隐藏 |
| 激活（修饰键 active、符号层中的 lang、转义中的空格） | `text` | `key` | `bg` |
| 锁定 | 同上（不画角点） | | |

四色（深 / 浅，无边框思路，灰度顺序照原型）：`bg` `#000`/`#f7f7f7`，`key` `#111`/`#fff`（按键只比背景亮一档，淡化边界），`text` `#fff`/`#111`（对比最强），`sub` `#555`/`#9e9e9e`（向背景方向退让：深色压暗、浅色提亮，拉开与主字的对比）。

单键（无上下滑）只居中显示主字。

### 4.3 候选与展开

| 元素 | 规则 |
| --- | --- |
| 候选行 | 高度 32，背景 = `bg`；竖屏可变宽：最小 2 键宽，偶数倍键宽（2/4/6/8/10 键 = 140/284/428/572/716），按 10 键一行装箱，左起 2、间距 4；不缩写 |
| 候选格 | 文字居中 32px；按下 → 底色 `text`、文字 `key`；超一格宽的候选格在该行内占多格 |
| 展开面板 | 仅 `composing && expanded`；覆盖主键区（y=36..356），背景 `bg`；流式行：按 10 键一行装箱，行高 1 或 2 行（超整行宽的候选折成 2 行，占 68px）；从常驻行的下一行接续 |
| 功能行 | 展开与符号层下都保留；候选行也保留 |
| 拼音行 | 仅 `composing` 或 `escape` 时出现；32px；文字色 `text`；左内边距 2；与候选行之间 4px 由背景填满 |

### 4.4 层级

| 层 | 内容 |
| --- | --- |
| 字母层 | 候选行 + 3 键行 + 功能行 |
| 符号层 | 候选行（空）+ 3 行符号格 + 功能行 |
| 展开层 | 候选行 + 展开面板 + 功能行 |

符号层与展开层都**不渲染字母键与方向键**。

## 6. 平台差异（必须逐条确认，其余一律照原型）

| 编号 | 差异 | 处理 |
| --- | --- | --- |
| D1 | 拼音行在原型中浮在键盘**外**（键盘 496，浮层在键盘上方） | 机制照系统输入法：拼音**不写入应用输入框**，由 IME 自己画在键盘外（与键盘同 token 的非触摸浮层），键盘恒 496；样式仍按原型 `.floating-preedit`：Unifont 32px、候选条同色底、主字色、左右 2px 内边距、无圆角、与键盘上沿隔 4px 并用同色补满（看起来与候选行连成一块） |
| D2 | 方向键在原型里自绘文本框并做行列移动 | 原生改为发 `DPAD_*` 给编辑器，行为取决于编辑器实现 |
| D3 | `Esc` 在原型里只记日志 | 原生发送 `KEYCODE_ESCAPE`（你要求生效） |
| D4 | 符号/候选分页 | 改为按行、多行、非平滑滚动（你已指定）。候选滚动把**常驻候选行**算进同一序列：滚第 n 行时常驻行显示第 n 行、展开面板从第 n+1 行接续，到末行停；收起展开时回第 0 行。竖屏候选格改为可变宽：最小 2 键宽、偶数倍键宽（2/4/6/8/10 键），按 10 键一行装箱，不缩写；单个候选超过整行宽（>716px）时折行、占 2 行高，展开面板里完整显示；常驻行仍 1 行高，超长词只露首行 |
| D5 | 页码指示为 `1/N 页` | 改行滚动后显示 `1/43 行` 之类 |
| D6 | 收起键盘 | 长按确认 → `requestHideSelf` |
| D7 | 浏览器 click 去重 | 原生无此问题，不实现 |
| D8 | 原型有 40 字拼音上限 | 原生由 libime 缓冲，保留语义即可（超长不追加） |
| D9 | ctrl/alt 组合键在原型里只记录、不发送 | 原生：未组词时按物理键位发 KeyEvent——字母、数字、ASCII 标点（含 Shift 层，如 `!` `@` `[` `;`）→ 对应 keyCode + `META_CTRL`/`META_ALT`（可再叠 `META_SHIFT`）；方向键、删除、Tab、Esc 同理；中文标签先经 NFKC 折叠（`！`→`!`）；无物理键码的符号（`……`、`×`、`￥`）仍按文本插入；组词中仍拦截 |
| D10 | 原型锁定修饰键时右上角画 6×6 角点 | 原生不画角点（你的要求）；锁定态只表现为反色 + 不自动取消 |
| D11 | 中文 `f` 键上下滑在原型里是固定 `“` / `‘` | 改为循环：上滑依次 `“` `”` `“`…，下滑依次 `‘` `’` `‘`…，键上标签随之变化；英文模式仍是 `"` / `'` |
| D12 | 原型无内部命令面板 | `\hp` 打开命令面板（不上屏），复用候选区：可变宽、可展开（确认切换）、可点按、可滚动；条目 `sc/tc/dk/lt/au`。`dk/lt/au` 覆盖/恢复系统深浅色；主题与简繁持久化到 `SharedPreferences`。词典为简体数据，`tc` 用平台 ICU `Hans-Hant` 转换候选与上屏文本，无可用转换数据时保持原文 |

## 7. 代码结构（已冻结）

| 文件 | 对应原型 | 职责 |
| --- | --- | --- |
| `KbdData.java` | `data.js` | 纯数据：标点映射、26 键、竖/横三组行、符号表、转义命令、内部命令表 `COMMANDS`（code/label/action 单一数据源） |
| `KbdLayout.java` | `layout.js` | 纯几何：竖屏/横屏两套档位；候选流式装箱（偶数键宽、超长跨行） |
| `KbdRenderer.java` | `view.js` | 只画：竖/横分层、命令面板、转义、候选；不持状态 |
| `KbdGestures.java` | `input.js` | 只识别：竖/横命中、长按/连发/滑动/滚动；产出语义事件 |
| `KbdApp.java` | `app.js` | 唯一状态持有者：输入、候选、转义、命令面板、主题/简繁；不绘制 |
| `KbdInputView.java` | — | Android View 适配：Canvas Sink、触摸转发、方向重建、长按计时 |
| `KbdPreeditView.java` | `.floating-preedit` | 键盘外拼音浮层（32px、文字宽、无圆角、4px 补满） |
| `KbdUi.java` | — | 夜间判定 + Unifont 加载（三处共用） |
| `KbdIme.java` | — | 生命周期 + `KbdApp.Host`（浮层、KeyEvent、ICU 简繁、SharedPreferences） |
| `EngineBridge` / `LibimeEngine` / `EngineData` | — | 引擎接口 / JNI 封装 / assets 解压 |

约束：`KbdGestures` 不写状态、`KbdRenderer` 不写状态、`KbdApp` 不碰 Canvas/Android；`KbdLayout` 只做数值。

## 8. 验收
